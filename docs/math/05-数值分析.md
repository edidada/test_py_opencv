# 数值分析：离散世界里的"近似解"（本科）

> 本科篇·分册 4/4。线代和高数给出连续模型，数值分析告诉你计算机如何**有限步、带误差**地执行它们。图像全是离散采样，所以这一课是 OpenCV 隐形参数（插值选择、容差、迭代次数）的解释器。

## 1. 插值：resize 的四种脾气

放大=凭空造像素=插值多项式：

| `cv2.INTER_*` | 数学 | 效果 |
|---|---|---|
| NEAREST | 零阶（取最近） | 快、锯齿，适合掩码/标签图 |
| LINEAR | 双线性（4 邻点线性组合） | 通用默认 |
| CUBIC | 双三次（16 邻点三次多项式） | 放大偏锐，文档图常用 |
| LANCZOS4 | 截断 sinc（sinc 基插值） | 最锐、可能振铃 |
| AREA | 面积加权（缩小抗锯齿） | 缩小首选 |

**龙格现象**：高次插值多项式在节点边缘会剧烈振荡 ⇒ 实用核限制阶数或截断（Lanczos 权衡主瓣/旁瓣）。你纠结"选哪种 INTER_"时，纠结的其实是这章内容。

```python
small = cv2.resize(img, (w//4, h//4), interpolation=cv2.INTER_AREA)
big   = cv2.resize(small, (w, h),      interpolation=cv2.INTER_CUBIC)
```

## 2. 数值微分与积分

- **差分近似导数**：Sobel 核=导数算子的离散化；中心差分截断误差 O(h²) 优于前向 O(h)。
- **数值积分/求和**：矩=黎曼和；**`cv2.integral` 积分图**=二维前缀和，O(1) 查矩形和——Haar 特征因此从 O(n²) 降到 O(1)。

## 3. 方程组、最小二乘与迭代

| 数值分析问题 | OpenCV 里的它 |
|---|---|
| 解线性方程组 | `cv2.solve`（LU+选主元） |
| 最小二乘 | `fitLine`、`findHomography`（DLT+SVD）、标定初解 |
| 迭代法 | LK 光流牛顿迭代、RANSAC 迭代采样、形态学迭代收敛 |
| 停止准则 | `cv2.TermCriteria`（容差+最大步数）——所有迭代 API 的公共参数 |

## 4. 病态、条件数与数值卫生

- 退化配置（点共线/纯旋转）⇒ `AᵀA` 条件数爆炸 ⇒ **先归一化再计算**（Hartley 归一化，`findHomography` 内部自动做）。
- `invert` 失败或病态时改用 `DECOMP_SVD` / `DECOMP_LU`。
- uint8 直接相加溢出回绕 ⇒ 饱和运算 `cv2.add` 或先转 float；中间量用 `CV_32F` 是"数值卫生"。
- 误差传播一行公式：重投影 1 像素 ≈ 深度误差 `Z²/(f·B)`——"双目基线为什么不能太短"的数值分析答案。
