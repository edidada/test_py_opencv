# 数值优化与李群：让模型"拟合得更准"（硕博）

> 硕博篇·分册 2/5。多视图几何给**模型**，数值优化给**算法**。硕士视觉的日常工作是解 `min Σ‖fᵢ(x)‖²`——位姿、三维点、标定参数都是它的变量。

## 1. 非线性最小二乘：GN 与 LM

```
min_x  F(x) = Σᵢ ‖fᵢ(x)‖²     （fᵢ = 重投影残差，x = 位姿/点/参数）
```

- **高斯–牛顿（GN）**：f(x+δ) ≈ f(x) + Jδ（一阶泰勒），每步解正规方程 `(JᵀJ)δ = −Jᵀf`。收敛快，但 JᵀJ 可能奇异、步长易失控。
- **Levenberg–Marquardt（LM）**：`(JᵀJ + λ·diag(JᵀJ))δ = −Jᵀf`。λ 大 ⇒ 小步梯度下降；λ 小 ⇒ 高斯牛顿——**在两个极限之间自适应插值**；残差变大加 λ，变小减 λ。信赖域视角（每步只在"模型可信半径"内优化）见 Nocedal 教材第 3、4、10 章。

| 函数 | 优化问题 |
|---|---|
| `cv2.solvePnPRefineLM` / `RefineIterative` | PnP 位姿 LM 精化 |
| `cv2.calibrateCamera` | 张正友初解（线性）→ LM 精修重投影误差（BA 雏形） |
| `cv2.stereoCalibrate` | 双目参数联合优化（用 flags 冻结子参数控条件数） |
| `cv2.findTransformECC` | 最大化扩展相关系数 ECC（牛顿型迭代） |
| `cv2.TermCriteria` | 停止准则：容差+最大步数 |

**光束法平差（BA）**：同时优化所有位姿+所有点。正规方程系数矩阵呈"每相机只连少量点"的稀疏箭头结构，Schur 消元先消点块——矩阵分块求逆的教科书案例，也是 Ceres/g2o 存在的理由（OpenCV 内置优化到 BA 规模就吃力）。

## 2. 李群与李代数：旋转的正确打开方式

R 是 9 变量、3 自由度的**流形**（SO(3)：RᵀR=I, detR=1）。把 9 个元素直接丢给优化器，迭代会漂出流形。解法：在**李代数 so(3)**（3 维切空间=轴角向量 φ）上优化，用指数映射搬回：

```
Rodrigues:  R = I + (sinθ/θ)[φ]ₓ + ((1−cosθ)/θ²)[φ]ₓ²
```

`[φ]ₓ` 反对称阵（叉积的矩阵形式）。SE(3)（4×4 齐次位姿阵）同理 6 维。**`cv2.Rodrigues` 就是这个映射的双向实现**；SLAM 后端（Ceres/g2o/Sophus）整个建立在"流形上的优化"。

**四元数**（`cv2.quatToMat`/`matToQuat`，4.5+）：另一套坐标卡；单位四元数 q∈S³ 是 SO(3) 的双覆盖——球面插值（slerp）转动画、IMU 姿态融合首选，避免欧拉角的万向锁。

## 3. 收敛性与矩阵计算的暗坑

- **雅可比稀疏性**：BA 的 J 每行只碰 1 相机+1 点的块——稀疏 Cholesky/QR 是规模化的前提。
- **正交约束处理**：直接优化 R ⇔ Rodrigues/四元数/QR 参数化（§2）或 Cayley 变换。
- **SVD 在病态配置**（共线点、纯旋转）上的数值行为决定标定是否"跑飞"——退化场景要加约束或换视角。
- **一行误差传播**：重投影 1 像素 ≈ 深度误差 `Z²/(f·B)`——双目基线太短为何深度不准，优化视角的定量答案。
