> 硕博篇·分册 4/5。把"不确定性"升级为**状态上的概率分布随时间演化**。卡尔曼滤波、粒子滤波、MOG2、视觉里程计、SLAM 全在这一框架里——Thrun 的《概率机器人》是应用舞台。

## 1. 贝叶斯滤波框架

跟踪维护后验 p(xₜ | z₁:ₜ)，两步递推：

```
预测： p̄(xₜ) = ∫ p(xₜ|xₜ₋₁)·p(xₜ₋₁) dx   （卷积：运动模型"抹开"分布）
更新： p(xₜ) ∝ p(zₜ|xₜ)·p̄(xₜ)            （贝叶斯公式乘似然）
```

| 假设 | 最优解法 | OpenCV |
|---|---|---|
| 线性+高斯 | 卡尔曼滤波（闭式：均值/协方差更新） | `cv2.KalmanFilter` |
| 非线性+高斯 | EKF（一阶泰勒线性化）/ UKF（sigma 点二阶矩） | 手写/外部库 |
| 非线性非高斯 | 粒子滤波（序贯蒙特卡洛，重采样） | 外部库（概念同 MCL） |

**`cv2.KalmanFilter` 四件套**：状态转移 A（运动学）、控制 B、观测 H（相机投影）、噪声协方差 Q/R（你信模型多一点还是信测量多一点）。增益 K 由协方差推出，是"预测↔观测"的自适应权重。SORT/ByteTrack 等现代多目标跟踪器的预测-关联骨架仍是它。

```python
kf = cv2.KalmanFilter(4, 2)                 # 状态 (x,y,vx,vy)，观测 (x,y)
kf.transitionMatrix = np.array([[1,0,1,0],[0,1,0,1],[0,0,1,0],[0,0,0,1]], np.float32)
kf.measurementMatrix = np.array([[1,0,0,0],[0,1,0,0]], np.float32)
kf.processNoiseCov     = np.eye(4, np.float32) * 1e-4
kf.measurementNoiseCov = np.eye(2, np.float32) * 1e-2
kf.predict(); kf.correct(meas.reshape(2, 1))
est = kf.statePre if False else kf.statePost
```

## 2. 分布建模在线学习：MOG2 与 EM

- **`cv2.createBackgroundSubtractorMOG2`**：每像素一个 GMM 的在线学习；当前值似然低 ⇒ 前景。KNN 版本（`...KNN`）用最近邻似然，对抗光照渐变更稳。
- **`cv2.ml.EM`**：通用 EM（E 步后验分配 / M 步重估），似然单调不降——含隐变量 MLE 的标准解法（本科篇 04 的深化）。
- **Cramér–Rao 下界**：Fisher 信息矩阵之逆给出"任何无偏估计误差方差的天花板"——设计滤波器前先看它值不值得做（统计估计理论的研究级入口）。

## 3. SLAM：状态估计的终极综合

同时估计**自身轨迹**与**环境地图**：

- **EKF-SLAM**：状态=位姿+全部地图点，协方差 O(n²) 爆炸；
- **图优化 SLAM**：位姿为节点、观测为边，稀疏 BA 变体（07 册的 Schur 消元再登场）；
- **粒子滤波 SLAM（FastSLAM）**：地图作为粒子上的假设——非线性非高斯的救赎。

OpenCV 没有完整 SLAM 模块，但三块积木齐活：`cv2.solvePnPRansac`（PnP 位姿）+ `cv2.findEssentialMat`（帧间相对运动）+ `cv2.triangulatePoints`（地图点）= 视觉里程计雏形。想系统化请读《概率机器人》第 2–4、8–11 章。
