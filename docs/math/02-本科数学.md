## 1. 线性代数：OpenCV 的母语

### 1.1 矩阵就是图像

8 位灰度图在内存里是 `H×W` 的 `numpy.uint8` 矩阵；彩色图是 `H×W×3`。Python 接口里 `cv2.Mat` 与 `numpy.ndarray` 无缝互换，**所有矩阵运算都直接作用于图像**：

```python
import cv2, numpy as np
img = cv2.imread("x.png", 0).astype(np.float32)
bright = cv2.add(img, np.full_like(img, 30.0))   # 每个元素 +30（饱和加，防溢出）
top    = img[:h//2, :]                            # 子矩阵 = ROI 裁剪
```

注意 uint8 直接 `img+30` 会溢出回绕，要用 `cv2.add`（饱和运算，封顶 255）或先转 float——这是"数值表示"这门隐形课的第一课。

| 线代概念 | OpenCV 函数 | 典型用途 |
|---|---|---|
| 矩阵乘法 | `cv2.matmul` / `@` | 变换复合：M = M₂·M₁ 一步到位 |
| 逆矩阵 | `cv2.invert` | 正变换↔逆变换（`warpAffine` 的 M_INVMAP） |
| 转置 | `cv2.transpose` | 换轴、协方差矩阵推导 |
| 行列式 | `cv2.determinant` | 可否求逆、面积定向、坐标手性 |
| 线性方程组 | `cv2.solve` | 最小二乘的正规方程 |
| 迹 | `cv2.trace` | 结构张量的特征和 = 梯度能量 |

**为什么"先转 30° 再转 60°"等于"转 90°"**：旋转矩阵相乘满足结合律，R(60)·R(30)=R(90)。理解矩阵乘法=线性变换的复合，就理解了相机模型 `P = K·[R|t]` 为什么是一条流水线。

### 1.2 向量空间、投影与最小二乘：OpenCV 的发动机

很多"测量问题"写成方程是**超定**的：n 个点拟合一条直线，2n 个方程、4 个未知数，无精确解。退而求其次：让残差平方和最小——这就是**最小二乘**。几何语言：把观测向量 b 投影到 A 的列空间上，投影系数 x 即所求；正交性给出**正规方程**：

```
AᵀA·x = Aᵀb
```

- **`cv2.fitLine`**：点到线垂直距离最小化（代数距离 vs 几何距离的差异，正是这条投影原理）。
- **多项式曲线拟合**：`cv2.fitLine` 的推广，设计矩阵每行 `[1, t, t², …]`。
- **标定棋盘格单应 DLT**：`A·h = 0` 型最小二乘，解取 A 的**最小奇异值对应的右奇异向量**（见 1.4）——`cv2.findHomography` 的内部。

```python
# 最小二乘拟合直线：y = kx + b
pts = np.array([[1, 2.1], [2, 3.9], [3, 6.2], [4, 7.8]])
A = np.c_[pts[:, 0], np.ones(len(pts))]
k, b = np.linalg.lstsq(A, pts[:, 1], rcond=None)[0]
# OpenCV 风格：
[vx, vy, x0, y0] = cv2.fitLine(pts.astype(np.float32), cv2.DIST_L2, 0, 0.01, 0.01)[ :, 0]
```

**`cv2.findHomography(src, dst)`** 求 3×3 矩阵 H 把平面 A 映射到 B（文档矫正、车牌视角归一化）：4 对点=8 方程=8 自由度（9 元素模掉尺度）。配合 `cv2.RANSAC` 剔误匹配。

```python
H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
warped = cv2.perspectiveTransform(pts, H)
```

### 1.3 特征值、二次型与 SVD：从矩阵里"榨"出结构

- **特征值/特征向量**：`Av = λv`——变换中"方向不变的轴"。旋转矩阵的实特征向量 = 旋转轴；对称矩阵特征值全为实数且可正交对角化。
- **`cv2.eigen` / `cv2.computeEigen`**：对称阵分解。
- **结构张量（角点检测的数学）**：对邻域 `M = Σ [Ix², IxIy; IxIy, Iy²]`（二次型的矩阵！）求 λ₁, λ₂。Shi–Tomasi 角点 `cv2.goodFeaturesToTrack` 取 min(λ₁,λ₂) 大者；Harris 角点用 `λ₁λ₂ − k(λ₁+λ₂)²`。特征值大小 = 该方向灰度变化强度——"椭圆拟合的转轴消项"（高中篇 5.1）在这里兑现为正交对角化。
- **SVD：A = U·S·Vᵀ**，任何矩阵都能分解。`cv2.SVDecomp`。应用：秩-k 图像压缩、伪逆、PCA、DLT 求零空间、本质矩阵分解。

```python
img = cv2.imread("lenka.png", 0).astype(np.float32) / 255
u, s, vt = cv2.SVDecomp(img)
for k in (5, 30, 150):
    low = (u[:, :k] * s[:k].T) @ vt[:k, :]      # 秩 k 近似
    cv2.imshow(f"rank{k}", np.clip(low, 0, 1))
```

奇异值衰减快 ⇒ 图像信息"能量集中" ⇒ JPEG/低秩补全（`cv2.inpaint`、`cv2.TrackerMedianFlow` 之外的 `cv2.lowrank` 思路）都吃这口饭。

- **PCA**：对一堆人脸（每张展平成向量）求协方差阵 `C = XᵀX/(n−1)` 的特征向量 = "特征脸"。`cv2.PCATraining` / `cv2.calcPCA`；现代替代品是 `cv2.dnn.TSNE` 可视化与自编码器。线代四大概念（基、正交、投影、特征值）的全套演示。
- **`cv2.decomposeProjectionMatrix`**：从 3×4 投影矩阵分离内参 K、旋转 R、平移 t 与相机中心——正交对角化 + QR 分解的综合应用。

### 1.4 数值稳定：归一化为什么重要

直接 DLT 在像素坐标上千时，`AᵀA` 条件数爆炸（病态）。标准做法：先平移缩放到 `[-1,1]²`（Hartley 归一化），解完再变回去——`cv2.findHomography` 内部自动做。"先缩放再计算"是数值分析贯穿全学科的军规。

## 2. 高等数学：导数、梯度与极值

### 2.1 偏导数 → 图像梯度 → 边缘

图像是二元函数 f(x, y)=灰度。**边缘 = 灰度突变 = 梯度**：

```
∇f = (∂f/∂x, ∂f/∂y)，  梯度方向垂直于等值线（边缘），  指向增长最快方向
```

离散世界用差分近似导数（一阶导定义 `(f(x+1)−f(x−1))/2` 的卷积形式）：

- **`cv2.Sobel` / `cv2.Scharr`**：一阶/二阶偏导核；Scharr 在 3×3 时旋转对称性更好（各向同性误差更小）。
- **`cv2.Canny`**：梯度幅值+方向 → 非极大值抑制（沿梯度方向比较只留脊线）→ 双阈值滞后连接。每一步都是导数语言。
- **方向导数与梯度点积**：`∇f·u` 是 u 方向的变化率——解释"Sobel 的 x/y 分量如何合成任意方向的响应"。

```python
gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)   # ∂f/∂x
gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)   # ∂f/∂y
mag = cv2.magnitude(gx, gy)                        # |∇f| = √(Ix²+Iy²)
```

### 2.2 泰勒展开 → 光流约束方程

Lucas–Kanade 光流（`cv2.calcOpticalFlowPyrLK`）核心一步：把 `I(x+dx, y+dy, t+dt)` 在 `(x,y,t)` 处一阶泰勒展开：

```
I + Iₓdx + I_ydy + I_tdt + … = I      （亮度恒定假设）
⇒ Iₓdx + I_ydy = −I_t                 （光流约束方程）
```

一个方程两个未知数 ⇒ 窗口内 25 个像素联立、最小二乘解 `(dx, dy)`——**一元泰勒 + 1.2 节最小二乘**的组合拳。迭代求解（牛顿法的思想）直到收敛。

### 2.3 一元/多元极值

- **必要条件 ∇f=0**：解释梯度方向垂直边缘、Canny 沿梯度做抑制。
- **Otsu 求"方差最大"的阈值**（见 3.2）、`solvePnPRefineLM` 求"重投影误差最小"的位姿（见硕博篇）——**OpenCV 的"智能"大多是求极值**。
- **隐函数与参数化**：圆 `x²+y²=r²` 的梯度 `(2x,2y)` 指向径向——Hough 圆检测用边缘法向找圆心方向的依据。

### 2.4 积分：面积、质矩与积分图

- **`cv2.contourArea`**：格林公式的离散版 `Σ(x_i·y_{i+1} − x_{i+1}·y_i)/2`。
- **`cv2.moments`**：零阶矩=面积（二重积分黎曼和）、一阶矩=质心、二阶矩=惯量；`cv2.HuMoments` 由此构造平移/旋转/尺度不变特征，用于形状匹配 `cv2.matchShapes`。
- **`cv2.integral`（积分图）**：`S(x,y)=Σ_{i<x,j<y} I(i,j)`，矩形区域和 O(1) 查询——支撑 Haar 级联人脸检测 `cv2.CascadeClassifier` 的加速（单特征计算从 O(n²) 降到 O(1)）。
- **卷积定理预告**：空间域卷积=频率域相乘（见 2.5）。

### 2.5 傅里叶变换

`cv2.dft` / `cv2.idft`：把图像从空间域换到频率域。

- 周期纹理（条纹、摩尔纹、屏幕拍摄网格）在频谱上是离散亮点 ⇒ 打掩码 `idft` 即去除。
- 高斯核的傅里叶变换仍是高斯且无负瓣 ⇒ 模糊不产生振铃；盒状核的 sinc 有负瓣 ⇒ 会振铃。
- 频域滤波模板尺寸与 `getOptimalDFTSize`；相位相关 `cv2.phaseCorrelate` 用频谱相位差算平移——平移定理 `f(x−d) ⇔ F(u)e^{-i2πud}` 的直接应用，亚像素配准神器。

```python
f = cv2.dft(np.float32(img), flags=cv2.DFT_SCALE | cv2.DFT_REAL_OUTPUT)
# 低通：中心留圆，其余置 0，再 idft
```

## 3. 概率论与数理统计：噪声、滤波与阈值

### 3.1 正态分布 → 高斯模糊与噪声建模

**`cv2.GaussianBlur` / `cv2.getGaussianKernel`**：核 `g(x) ∝ exp(−x²/2σ²)`。为什么是它？噪声常建模为高斯白噪声（独立同分布、方差 σ²），对这类噪声做均方误差最小的线性滤波，最优核恰是高斯形。工程换算 `ksize ≈ 6σ+1` 来自"正态变量落 ±3σ 外概率约 0.27%"。

常见噪声模型：高斯（`img + N(0,σ²)`）、椒盐（0/255 随机翻转→中值滤波最优）、泊松（光子计数噪声，σ²∝μ——暗区更噪的物理根源，`cv2` 之外的 RAW 处理天天谈）。

### 3.2 期望、方差 → Otsu 自动阈值

`cv2.threshold(..., cv2.THRESH_OTSU)`：遍历候选阈值 t，把像素分两类，计算类间方差

```
σ²(t) = ω₀ω₁(μ₀ − μ₁)²
```

取最大者。只用到期望与方差的定义——《概率论》第二章的直接应用，也是"判别准则"思想的第一课。同类：`cv2.meanStdDev` 输出均值/标准差三件套；PSNR `10·log₁₀(MAX²/MSE)` 是"噪声方差的 dB 表达"。

### 3.3 大数定律与直方图

直方图 = 概率分布的频率估计；样本越多越接近真分布（伯努利大数定律）。`cv2.equalizeHist` 把它整形为均匀分布（CDF 变换=概率积分变元的离散版）；`cv2.compareHist` 的巴氏距离/相关系数在比较两个经验分布。

### 3.4 贝叶斯公式 → 背景建模与分类

`p(前景|颜色) ∝ p(颜色|前景)·p(前景)`。**`cv2.createBackgroundSubtractorMOG2`**：每像素用高斯混合模型拟合历史颜色分布，当前值似然低 ⇒ 判前景。`cv2.ml.NormalBayesClassifier` 朴素贝叶斯分类器是显式版本（特征条件独立假设）。

### 3.5 参数估计：极大似然与矩估计

- **矩估计**：直方图均值/方差反推噪声 σ——`cv2.fastNlMeansDenoising` 的 h 参数标定经验由此来。
- **EM 算法**（`cv2.ml.EM`）：含隐变量的极大似然迭代（先猜聚类中心→分配→再算中心），GMM 学习的标准解法。

## 4. 数值分析：离散世界里的"近似解"

线代/高数给连续模型，数值分析告诉你计算机如何**有限步、带误差**地执行：

| 数值分析问题 | OpenCV 里的它 |
|---|---|
| 插值 | `cv2.resize` 双线性（4 邻点线性组合）/ 立方（16 点三次多项式）/ Lanczos4（sinc 基）；`warpAffine`/`remap` 反向映射取样 |
| 数值微分 | Sobel 差分核=导数算子的近似；中心差分截断误差 O(h²) 优于前向 O(h) |
| 解线性方程组 | `cv2.solve`（LU+主元）；DLT 用 SVD 求零空间 |
| 最小二乘 | `fitLine`、`findHomography`、标定初解 |
| 迭代法 | LK 光流牛顿迭代、RANSAC 迭代采样、阈值迭代 |
| 数值积分/求和 | 矩计算、`cv2.integral` 前缀和 |
| 病态与条件数 | 退化配置（点共线）⇒ 归一化坐标后 DLT；行列式接近 0 ⇒ `invert` 用 `DECOMP_SVD` |
| 误差与稳定性 | uint8 饱和运算 vs float 累积误差；`CV_32F` 中转是数值卫生 |

**插值多项式与振铃**：拉格朗日插值点过多会龙格振荡 ⇒ 立方插值限制阶数；Lanczos 用截断 sinc 权衡主瓣/旁瓣——"放大图像选哪种 INTER_" 的选型依据全在这一章。

```python
small = cv2.resize(img, (w//4, h//4), interpolation=cv2.INTER_AREA)   # 缩小抗锯齿
big   = cv2.resize(small, (w, h), interpolation=cv2.INTER_CUBIC)      # 放大偏锐
```
