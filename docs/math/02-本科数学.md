## 1. 线性代数：OpenCV 的母语

### 1.1 矩阵就是图像

一张 8 位灰度图在内存里就是一个 `H×W` 的 `numpy.uint8` 矩阵；彩色图是 `H×W×3`。`cv2.Mat` 与 `numpy.ndarray` 在 Python 接口里可以互换。**所有矩阵运算都直接作用于图像**：

```python
import cv2, numpy as np
img = cv2.imread("x.png")
bright = cv2.add(img, np.full_like(img, 30))   # 每个元素 +30
flip_half = img[:h//2, :]                       # 子矩阵
```

对应知识点：

| 线代概念 | OpenCV 函数 | 典型用途 |
|---|---|---|
| 矩阵乘法 | `cv2.matmul` / `@` | 连续变换复合：R₂·R₁ 一步到位 |
| 逆矩阵 | `cv2.invert` | 变换求逆：正变换↔逆变换 |
| 转置 | `cv2.transpose` | 坐标系换轴 |
| 行列式 | `cv2.determinant` | 判断矩阵可否求逆、面积定向 |
| 线性方程组求解 | `cv2.solve` | 单应/标定中最小二乘的正规方程 |

**为什么旋转两次等于乘一次矩阵**：仿射/透视变换都是矩阵乘法，复合变换 `M = M₂ @ M₁`。理解结合律，就理解了为什么相机标定的投影矩阵 `P = K·[R|t]`。

### 1.2 秩、零空间与最小二乘：单应矩阵的来历

`cv2.findHomography(src, dst)` 求一个 3×3 矩阵 H，把平面 A 的 4 个点映射到平面 B（文档照片矫正、车牌视角归一化的核心）。每对点给出 2 个方程，4 对点 = 8 个方程，未知数是 H 的 8 个自由度（尺度不定，9 个元素除一个）。方程写成 `A·h = 0`：

- **超定/无精确解时求最小二乘解**：解在 A 的零空间边缘，即**最小奇异值对应的右奇异向量**——这就是 DLT（Direct Linear Transform）算法，`cv2.findHomography` 的内部。
- 配合高中篇说过的 RANSAC（`cv2.RANSAC`）剔除误匹配点。

```python
H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
warped = cv2.perspectiveTransform(pts, H)
```

### 1.3 特征值与 SVD：从矩阵里"榨"出结构

- **`cv2.SVDecomp`**：任何矩阵 A = U·S·Vᵀ。图像压缩（保留前 k 个奇异值近似原图）、伪逆、PCA 都靠它。
- **`cv2.eigen` / `cv2.computeEigen`**：对称矩阵的特征分解。
- **`cv2.goodFeaturesToTrack`（Shi–Tomasi 角点）**：对每个邻域的梯度结构张量 `M = Σ [Iₓ², IₓI_y; IₓI_y, I_y²]` 求特征值 λ₁, λ₂，取 min(λ₁,λ₂) 大者为角点——特征值大小 = 该方向灰度变化强度。
- **`cv2.decomposeProjectionMatrix`**：从投影矩阵分离出内参 K、旋转 R、平移 t 和相机中心——正交矩阵与行列式的综合运用。
- **本质矩阵分解** `cv2.recoverPose`：E = U·diag(1,2,1)·Vᵀ 形式的 SVD 分解，得到 4 组 (R,t) 候选。

```python
import cv2, numpy as np
img = cv2.imread("lenka.png", 0).astype(np.float32) / 255
u, s, vt = cv2.SVDecomp(img)
for k in (5, 30, 150):
    low = (u[:, :k] * s[:k].T) @ vt[:k, :]          # 秩 k 近似
    cv2.imshow(f"rank{k}", np.clip(low, 0, 1))
```

### 1.4 PCA（主成分分析）

`cv2.PCATraining` / `cv2.calcPCA`：对一堆人脸图（每张展平成向量）求协方差矩阵的特征向量——"特征脸"（Eigenfaces）。这是线代四大概念（基、正交、投影、特征值）的一次全套演示。

## 2. 高等数学：导数、梯度与极值

### 2.1 偏导数 → 图像梯度 → 边缘

图像可看作二元函数 f(x, y)=灰度。**边缘 = 灰度变化最剧烈处 = 梯度模型**：

```
∇f = (∂f/∂x, ∂f/∂y)
```

离散世界里用差分近似导数：

- **`cv2.Sobel` / `cv2.Scharr`**：一阶/二阶偏导的有限差分核（如 x 方向核 `[-1,0,1]` 就是一阶导数定义 `(f(x+1)-f(x-1))/2` 的卷积形式）。
- **`cv2.Canny`**：先算梯度幅值与方向，再做非极大值抑制（沿梯度方向比较，只保留脊线）与双阈值——每一步都是导数语言。
- **`cv2.phaseCorrelate`、光流**：建立在"灰度对位置的一阶偏导"之上。

```python
gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)  # ∂f/∂x
gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)  # ∂f/∂y
mag = cv2.magnitude(gx, gy)                       # |∇f|
```

### 2.2 泰勒展开 → 光流约束方程

Lucas–Kanade 光流（`cv2.calcOpticalFlowPyrLK`）的核心一步：

```
I(x+dx, y+dy, t+dt) ≈ I + Iₓ·dx + I_y·dy + I_t·dt
```

令其等于 I（亮度恒定），得 `Iₓ·dx + I_y·dy = −I_t`——一元一次泰勒展开直接产出运动估计方程，再用最小二乘解窗口内所有像素。**本科"泰勒公式"一章最出圈的应用之一。**

### 2.3 极值与链式法则

- **阈值/配准/标定的本质都是求极值**：Otsu 求"方差最大"的阈值；`solvePnP` 求"重投影误差最小"的位姿（见硕博篇）。
- **链式法则**：`cv2.dnn` 网络训练的反向传播就是多元链式法则的流水线（硕博篇展开）。
- **二元函数极值的必要条件 ∇f=0**：解释了为什么梯度方向垂直于等值线——Canny 中"沿梯度方向做抑制"由此而来。

### 2.4 积分：面积、质矩与二值统计

- **`cv2.contourArea`**：多边形面积 = 格林公式（曲线积分→面积分）的离散版，`Σ(x_i·y_{i+1} − x_{i+1}·y_i)/2`。
- **`cv2.moments`**：零阶矩=面积、一阶矩=质心、二阶矩=惯性——重积分概念逐像素求和实现，`cv2.HuMoments` 由此构造旋转不变特征。
- **二重积分 ≈ 像素求和**：`cv2.sumElems`、直方图归一化都是黎曼和。

### 2.5 傅里叶级数/变换

`cv2.dft` / `cv2.idft`：把图像从空间域换到频率域。周期纹理（条纹、摩尔纹）在频域是离散亮点，打上掩码再 `idft` 即滤波。`cv2.GaussianBlur` 的核就是正态曲线采样——高斯函数的傅里叶变换仍是高斯，这保证了"模糊不产生振铃"。

```python
f = np.fft.fftshift(np.abs(cv2.dft(img)))   # 或用 cv2.dft + magnitude
```

## 3. 概率论与数理统计：噪声、滤波与阈值

### 3.1 正态分布 → 高斯模糊

**`cv2.GaussianBlur` / `getGaussianKernel`**：核 `g(x) ∝ exp(−x²/2σ²)`，`sigmaX` 越大越糊。为什么用它？噪声常建模为高斯白噪声，对它做最小均方误差的线性滤波，最优核恰是高斯形。σ 与核尺寸的工程关系 `ksize ≈ 6σ+1` 来自"正态变量落在 ±3σ 外概率约 0.27%"。

### 3.2 期望、方差 → Otsu 自动阈值

`cv2.threshold(..., cv2.THRESH_OTSU)`：遍历候选阈值 t，把像素分成前景/背景两类，计算**类间方差** σ²(t)=ω₀ω₁(μ₀−μ₁)²，取最大者。全文只用期望与方差的定义——本科《概率论》第二章的直接应用。

### 3.3 贝叶斯与条件概率 → 背景建模

`cv2.createBackgroundSubtractorMOG2`：每个像素用**高斯混合模型**拟合其历史颜色分布，当前值似然低 ⇒ 判为前景（运动物体）。背后是贝叶斯公式 + 多峰分布思想（严格的贝叶斯递推在硕博篇的卡尔曼滤波）。

### 3.4 大数定律与直方图

直方图是概率分布的**频率估计**；`cv2.equalizeHist` 是把它"整形"为均匀分布；`cv2.compareHist` 的巴氏距离/相关性度量，本质是在比较两个经验分布。

### 3.5 随机变量数字特征 → 图像质量

均值、方差、标准差是 `cv2.meanStdDev` 的三件套；信噪比 SNR、PSNR（`10·log₁₀(MAX²/MSE)`）是噪声评估的语言。

## 4. 数值分析：离散世界里的"近似解"

线代/高数给出连续模型，数值分析告诉你计算机如何**有限步、带误差地**执行它们：

| 数值分析问题 | OpenCV 里的它 |
|---|---|
| 插值 | `cv2.resize` 的双线性/立方插值：放大图像时在 4/16 个邻点构造插值多项式；`INTER_LANCZOS4` 用 sinc 基 |
| 解线性方程组 | `cv2.solve`（LU/选择主元），DLT 用 SVD 求零空间向量 |
| 最小二乘 | `fitLine`、`findHomography`、标定优化 |
| 迭代法 | LK 光流的牛顿迭代、RANSAC 的迭代采样 |
| 数值积分/求和 | 卷积、矩计算的前缀和优化（`cv2.integral` 积分图） |
| 病态与条件数 | 退化配置（点共线）下 H 求解不稳定 ⇒ 归一化坐标后再 DLT，正是"先缩放再求解"的数值稳定技巧 |

**积分图**（`cv2.integral`）是"数列前缀和"（高中篇 6.2）的二维版：O(1) 查任意矩形区域和，让 Viola–Jones 人脸检测（`cv2.CascadeClassifier`）的 Haar 特征计算快了三个数量级。
