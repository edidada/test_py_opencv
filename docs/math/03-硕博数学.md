## 1. 射影几何：像素与三维点的真正关系

### 1.1 针孔模型与齐次坐标：把除法藏进矩阵

相似三角形给投影方程：`x = f·X/Z, y = f·Y/Z`。除法不是线性运算，矩阵写不下。射影几何的解法：**给坐标加一维**，且 `(λX, λY, λZ, λ) ≡ (X, Y, Z)`（λ≠0，尺度等价）。投影于是变成一次矩阵乘法：

```
s·[u, v, 1]ᵀ = K · [R | t] · [X, Y, Z, 1]ᵀ
```

- `s`：齐次尺度（深度）；`Z` 越大视差越小，`1/Z` 透视缩形的代数根源。
- `K = [fx 0 cx; 0 fy cy; 0 0 1]`：内参（焦距+主点+像素尺度）。
- `[R|t]`：外参（旋转+平移），世界系→相机系。

**一条三维→二维流水线 = 一个 3×4 矩阵**。这就是 `cv2.calibrateCamera` 返回的 cameraMatrix/rvecs/tvecs 的全部含义，`cv2.projectPoints` 只是把它执行一遍。

射影几何回答的工程问题：
- **为什么 4 点定单应**：射影变换 8 自由度（9 元素模尺度），每点 2 方程。
- **灭点与无穷远元素**：铁轨照片里平行线交于灭点——方向向量在像平面的像点（w=0 的无穷远点映射为有限点）。`cv2.decomposeProjectionMatrix` 分解出的相机中心 = 零空间向量。
- **对合、二次曲线**：圆环点（circular points）隐含在绝对二次曲线 Ω∞ 中，标定内参即"找让 Ω∞ 变圆的那条线"——自标定方法（Zhang 法本质）的几何语言。

### 1.2 失真模型：多项式为什么长那样

真实镜头不是针孔。径向畸变（枕形/桶形）用幂级数近似：

```
x_d = x(1 + k₁r² + k₂r⁴ + k₃r⁶),  y_d 同理 + 切向项 (p₁, p₂)
```

这是"任何光滑映射局部可用多项式逼近"（泰勒思想的又一次出场）；OpenCV 鱼眼模型改用等距投影 `θ = w·r`（`cv2.fisheye` 模块）。矫正即反向映射：`cv2.undistort` / `initUndistortRectifyMap` + `remap`。

### 1.3 对极几何：两台相机之间的数学

两相机看同一场景，对应点被约束在极线上——**三维重建的免费午餐**（不需要任何先验）。数学：

```
x₂ᵀ · F · x₁ = 0     （F：基础矩阵，像素坐标版，7 自由度）
F = K₂⁻ᵀ · E · K₁⁻¹,   E = [t]ₓ · R（本质矩阵，内参已知时）
```

| 函数 | 数学内容 |
|---|---|
| `cv2.findFundamentalMat` | 对极约束线性解（8 点法）或非线性（7 点法）+ RANSAC |
| `cv2.findEssentialMat` | E 的 5 点法（多项式求根，Stewenius/Nister） |
| `cv2.recoverPose` | E 的 SVD 分解出 4 组 (R,t)，用"点在两相机前方"消歧 |
| `cv2.triangulatePoints` | 两射线最近点 = 线性最小二乘（齐次 DLT） |
| `cv2.stereoRectify` | 求相似变换使极线水平对齐——旋转+射影的复合 |
| `cv2.reprojectImageTo3D` | 视差 d → 深度 Z = f·B/d（三角测量的连续版） |
| `cv2.computeSceneDepth`、`StereoSGBM` | 深度图：匹配代价 + 动态规划（图上推断） |

```python
E, mask = cv2.findEssentialMat(p1, p2, K, method=cv2.FM_RANSAC)
_, R, t, _ = cv2.recoverPose(E, p1, p2, K)
pts4 = cv2.triangulatePoints(P1, P2, p1[:2], p2[:2])
X = (pts4[:3] / pts4[3]).T
```

**P3P/EPnP**（`cv2.solvePnPRansac`）：已知 3D-2D 对应，3 点+1 参考点直接闭式解位姿（解多项式方程组）；EPnP 把 3D 点表示为 4 个控制点的凸组合（重心坐标），4 点即解——计算几何 + 线性代数的组合技巧。

### 1.4 李群与李代数：旋转的正确打开方式

R 是 9 个变量、3 个自由度的流形（SO(3)：RᵀR=I, detR=1）。直接把 R 的 9 个元素丢给优化器，迭代会漂出流形。解法：在**李代数 so(3)**（3 维切空间，轴角向量 φ）上优化，用指数映射搬回：

```
Rodrigues:  R = I + (sinθ/θ)[φ]ₓ + ((1−cosθ)/θ²)[φ]ₓ²
```

`[φ]ₓ` 反对称阵（叉积的矩阵形式）。SE(3)（旋转+平移，4×4 齐次矩阵）同理 6 维。**`cv2.Rodrigues` 就是这个映射的正反两向**。SLAM 后端（Ceres/g2o/Sophus）整个建立在"流形上的优化"之上；OpenCV 的标重在内部也用正交约束的 3 参数表示。

**四元数**（`cv2.quaternion` 系列，4.5+）：另一套坐标卡，单位四元数 q∈S³ 是 SO(3) 的双覆盖——球面插值（slerp）转动画像、避免万向锁，游戏与 IMU 融合首选。

## 2. 非线性最小二乘与数值优化：让模型更准

多视图几何给**模型**，数值优化给**算法**。硕士视觉的日常：

```
min_x  F(x) = Σᵢ ‖fᵢ(x)‖²     （x = 位姿/三维点/参数，fᵢ = 重投影残差）
```

### 2.1 高斯牛顿与 Levenberg–Marquardt

- **高斯牛顿（GN）**：f(x+δ) ≈ f(x) + Jδ（一阶泰勒），每步解正规方程 `(JᵀJ)δ = −Jᵀf`。收敛快但 JᵀJ 可能奇异/步长失控。
- **LM**：`(JᵀJ + λ·diag(JᵀJ))δ = −Jᵀf`。λ 大→小步梯度下降，λ 小→GN：**在两个极限间自适应插值**；失败加大 λ，成功减小 λ。信赖域视角（每步在"模型可信半径"内取最优）是 Nocedal 教材第 3、4、10 章的完整内容。

| 函数 | 优化问题 |
|---|---|
| `cv2.solvePnPRefineLM` / `RefineIterative` | PnP 位姿 LM 精化（目标=重投影误差） |
| `cv2.calibrateCamera` | 张正友法初解（线性）→ LM 最小化重投影误差（非线性精修=BA 雏形） |
| `cv2.stereoCalibrate` | 双目参数联合优化（条件数更大，故有 flags 冻结子参数） |
| `cv2.findTransformECC` | 最大化扩展相关系数 ECC（迭代牛顿型） |
| `cv2.TermCriteria` | 停止准则：梯度容差/最大步数——收敛性语言 |

**光束法平差（BA）**：同时优化所有位姿+所有点，正规方程系数矩阵有"每相机连少量点"的稀疏箭头结构，Schur 消元先消点块——矩阵分块求逆的教科书案例，也是 Ceres/g2o 存在的理由（OpenCV 内置优化到此规模就吃力了）。

### 2.2 凸优化：可全局求解的那一类

凸集上的凸函数：局部最优=全局最优。支撑函数：

```
SVM（cv2.ml.SVM）:  min ½‖w‖² + C·Σξᵢ  s.t. yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ
                    对偶化 → 只依赖内积 → 核技巧（线性/多项式/RBF/chi2）
```

KKT 条件 ⇒ 最优解只由支持向量决定（"支持向量"名字来历）。对偶、拉格朗日乘子、核函数在本科高数/线代都没有直接铺垫，是硕博课《凸优化》（Boyd）的核心——教材免费 PDF 在作者主页，中文纸质版见文末 ISBN。

**图割（graph cut）**：二值分割能量 E(标签)=数据项+平滑项，若子模则可写成最小割精确求解——`cv2.grabCut` 的迭代内核（GMM 数据项 + α-expansion 式图割平滑）。组合优化与最大流最小割定理（对偶定理在离散域的孪生）在此汇合。

| 函数 | 数学点 |
|---|---|
| `cv2.ml.SVM` / `LogisticRegression` / `NormalBayesClassifier` | 凸 QP、对偶、核技巧 |
| `cv2.grabCut` | 图割能量最小化 |
| `cv2.watershed` | 形态学测地距离（偏微分方程视角的"最短路径"） |
| `cv2.fastNlMeansDenoising` | 权重由相似度的核回归（非参数统计） |

## 3. 概率状态估计：跟踪、滤波与 SLAM

把"不确定性"升级为**状态上的概率分布随时间演化**。

### 3.1 贝叶斯滤波框架

跟踪维护后验 p(xₜ | z₁:ₜ)，两步递推：

```
预测： p̄(xₜ) = ∫ p(xₜ|xₜ₋₁) p(xₜ₋₁) dx     （卷积 = 运动模型"抹开"分布）
更新： p(xₜ) ∝ p(zₜ|xₜ) · p̄(xₜ)              （贝叶斯公式乘似然）
```

- **线性+高斯 ⇒ 卡尔曼滤波**：后验保持高斯，均值 Σ 闭式更新。`cv2.KalmanFilter`：转移矩阵 A（运动学）、观测矩阵 H（投影）、增益 K（协方差推出的"信预测还是信观测"权重）。目标跟踪（如 SORT/ByteTrack 的预测-关联骨架）、IMU 融合用它。
- **非线性 ⇒ EKF/UKF**：EKF 用雅可比一阶泰勒线性化（本科泰勒再出场）；UKF 用 sigma 点传播均值/协方差（二阶矩意义，无导数）。
- **非线性非高斯 ⇒ 粒子滤波（序贯蒙特卡洛）**：撒 N 个样本近似后验，重采样偏向高似然粒子——大数定律保证 N→∞ 收敛。
- **估计的性能下限**：Cramér–Rao 下界（Fisher 信息矩阵的逆）告诉你"任何无偏估计误差方差的天花板"——设计滤波器前先看它值不值得做。

```python
kf = cv2.KalmanFilter(4, 2)                 # 状态 (x,y,vx,vy)，观测 (x,y)
kf.transitionMatrix = np.array([[1,0,1,0],[0,1,0,1],[0,0,1,0],[0,0,0,1]], np.float32)
kf.measurementMatrix = np.array([[1,0,0,0],[0,1,0,0]], np.float32)
kf.processNoiseCov   = np.eye(4, dtype=np.float32) * 1e-4
kf.measurementNoiseCov = np.eye(2, dtype=np.float32) * 1e-2
kf.predict(); kf.correct(meas.reshape(2, 1))
```

### 3.2 概率图模型与 EM

- MOG2 背景建模 = 每像素一个 GMM 的在线学习；通用 EM 实现 `cv2.ml.EM`（含隐变量极大似然：E 步求后验分配、M 步重估参数，单调升似然的坐标上升）。
- 条件随机场（CRF）精化分割边界、马尔可夫随机场去噪——图模型语言（Bishop PRML 第 8 章）。
- 立体匹配 SGBM（`cv2.StereoSGBM`）：沿 8/16 条路径动态规划聚合代价，可看作链式图上的最大后验推断——"路径=图结构，DP=推断"。

### 3.3 SLAM：状态估计的终极综合

同时估计自身轨迹与环境地图：EKF-SLAM（协方差爆炸 O(n²)）、图优化 SLAM（稀疏 BA 的变体，位姿为节点、观测为边）、粒子滤波/FAST-SLAM（把地图作为粒子上的假设）。OpenCV 本身没有完整 SLAM 模块，但 `cv2.solvePnPRansac` + `cv2.findEssentialMat` + `cv2.triangulatePoints` 就是视觉里程计的三块积木（配套概率框架读 Thrun《概率机器人》第 2–4 章）。

## 4. 深度学习数学：`cv2.dnn` 背后的理论

推理（`readNetFromONNX` + `Net.forward`）不需要数学；训练与改造需要：

- **前向 = 复合函数逐层求值；反向 = 链式法则在计算图上的动态规划**。每层梯度 = 局部雅可比 × 上游梯度。卷积层对图像求梯度 = 一次转置卷积——本科"偏导+卷积"的矩阵化；im2col 把卷积写成 GEMM，所以 GPU 利用率是"线代乘法"级别的。
- **Softmax + 交叉熵的漂亮相消**：`∂L/∂logits = p − y`（预测减真值）——对数似然与指数族的一阶导数练习，也是"分类损失"梯度如此干净的原因。
- **优化器谱系**：SGD → 动量（梯度 EMA）→ Adam（一阶+二阶矩偏差修正）——全部是数值优化 + 统计平滑（大数定律控制小 batch 梯度噪声）。
- **正则化 = 贝叶斯先验**：L2 权重衰减 ⇔ 高斯先验的 MAP；Dropout ⇔ 近似贝叶斯集成；BatchNorm ⇔ 重新参数化让优化地形更条件良好（凸性视角的坐标变换）。
- **信息论**：熵、KL 散度、互信息度量分布差异；`dnn.NMSBoxes` 的 IoU = 面积交并比（测度论的最小可用版）。
- **注意力 = 加权平均**：Attention(Q,K,V) 的 softmax(QKᵀ/√d)V 就是"按相似度加权取值"——高中加权平均+点积的深度学习版。

| cv2 API | 数学点 |
|---|---|
| `dnn.readNetFromONNX / readNet / Net.forward` | 计算图、张量（高维数组+广播=线代推广） |
| `dnn.BlobFromImage` | 均值减法（中心化）、尺度归一（方差标准化） |
| `dnn.NMSBoxes` | 集合覆盖、IoU 面积测度 |
| YOLO/SSD 框解码 | 坐标参数化（中心点+对数宽高回归） |
| `dnn.objdetect`、`face` 模块 | 分类损失与难例挖掘（统计抽样） |

## 5. 矩阵计算与数值线性代数（研究级补充）

多视图优化的命门：
- SVD 在病态/退化配置（点共线、纯旋转）上的数值行为；
- 正交约束的处理：直接优化 R 会离开流形 ⇒ Rodrigues/四元数/QR 参数化（1.4 节）；
- 大规模稀疏正规方程：Cholesky + 稀疏分解，BA 的 Schur 补结构；
- 条件数与残差敏感性：重投影误差的 1 像素 ≈ 深度误差 `Z²/(f·B)`——双目基线太短为什么深度不准，一行推导讲清。

`cv2.SVDecomp` / `cv2.solve` 够用，但研究规模下换 Eigen/Ceres。

## 8. 三篇合读：一条公式的成长史

以"旋转"回看整条数学链：

1. **高中**：cos/sin 与单位圆 → 会转一张图（`getRotationMatrix2D`）。
2. **本科**：矩阵乘法与正交阵 → 旋转可复合、可求逆；特征向量给出旋转轴；最小二乘让"转多少度"从猜变成解。
3. **硕博**：SO(3) 是流形 → Rodrigues/四元数是坐标卡；优化位姿时必须在李代数上更新，否则迭代"漂"出旋转矩阵集合（`calibrateCamera`/BA 内部如此）。

再看"投影"：

1. **高中**：相似三角形 → 小孔成像的直觉。
2. **本科**：齐次坐标前你只会仿射（平行线保持平行）——可照片里铁轨明明会相交。
3. **硕博**：射影变换统一一切，标定把真实镜头逐参数"收编"进 K·[R|t]。
