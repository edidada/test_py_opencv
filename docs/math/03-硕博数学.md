## 1. 射影几何：像素与三维点的真正关系

### 1.1 齐次坐标：把"透视除法"藏进矩阵

本科线代告诉我们：线性变换=矩阵乘法。但针孔相机模型是：

```
x = f·X/Z,   y = f·Y/Z      （相似三角形）
```

除法不是线性的。射影几何的解法优雅得出人意料：**给坐标加一维**。三维点用 `(X, Y, Z, 1)` 表示，且 `(λX, λY, λZ, λ) ≡ (X, Y, Z)`（λ≠0，尺度等价）。投影写成矩阵：

```
s·[u, v, 1]ᵀ = K · [R | t] · [X, Y, Z, 1]ᵀ
```

- `s` 是未知尺度（齐次允许相差一个非零因子）；
- `K`（内参矩阵：焦距 fx, fy + 主点 cx, cy）把相机坐标变像素；
- `[R|t]`（外参：旋转+平移）把世界坐标变相机坐标。

整条"三维→二维"流水线 = **一个 3×4 矩阵乘法**。这就是 `cv2.calibrateCamera` 返回的 cameraMatrix / rvecs / tvecs 的全部含义，也是 `cv2.projectPoints` 的一行实现。

射影几何还回答了两个工程问题：

- **为什么 4 个点定单应而不是 3 个**：射影变换 8 自由度（9 元素模掉尺度），每点 2 方程 ⇒ 4 点。
- **无穷远点、灭线**：铁轨照片里平行线交于"灭点"——平行线方向向量在 π 平面的像；`cv2.decomposeProjectionMatrix` 分解出的相机中心、`cv2.Rodrigues` 的旋转，都是这个模型的部件。

### 1.2 对极几何：两台相机之间的数学

两个相机看同一场景，对应点被约束在一条极线上——这是**不带任何先验的三维重建起点**。数学上：

```
x₂ᵀ · F · x₁ = 0        （F：本质矩阵的"像素坐标"版）
```

F 由 7 对匹配点线性求出（Again 是 SVD 找零空间），F 分解出 R、t（`cv2.recoverPose`）。相关 API：

| 函数 | 数学内容 |
|---|---|
| `cv2.findFundamentalMat` | 对极约束 + RANSAC，7/8 点法 |
| `cv2.findEssentialMat` | 内参已知时的本质矩阵 E = [t]ₓR，5 点法 |
| `cv2.recoverPose` | E 的 SVD 分解出 4 组 (R,t)，用三角化消歧 |
| `cv2.triangulatePoints` | 两射线最近点 = 线性最小二乘三角化 |
| `cv2.stereoRectify` | 把两图重采样到共线光心、同一极线（行对齐），依据是射影变换+旋转 |
| `cv2.reprojectImageTo3D` | 视差 d → 深度 Z = f·B/d（对极几何的微积分练习） |
| `cv2.solvePnPRansac` | 已知 3D-2D 对应，P3P/EPnP + RANSAC（射影几何 + 组合数学） |

```python
E, mask = cv2.findEssentialMat(p1, p2, K, method=cv2.FM_RANSAC)
_, R, t, _ = cv2.recoverPose(E, p1, p2, K)
pts4d = cv2.triangulatePoints(P1, P2, p1[:2], p2[:2])
```

**李群 / 旋转的参数化**（`cv2.Rodrigues` 的核心）：旋转矩阵 R 是满足 RᵀR=I、det R=1 的 9 个变量、3 个自由度——直接优化会偏离流形。Rodrigues 公式在**轴角向量**（3 维，李代数 so(3) 的坐标）与 R 之间双向换算：

```
R = I + sinθ·[k]ₓ + (1−cosθ)·[k]ₓ²
```

`[k]ₓ` 是反对称矩阵（叉积的矩阵形式，本科线代）。现代 SLAM 库（Ceres、g2o、Sophus）把李群/李代数用到底；OpenCV 的 `Rodrigues` 是它的入口。

## 2. 非线性最小二乘与数值优化：让模型"拟合得更准"

多视图几何给出**模型**，数值优化给出**算法**。硕士阶段视觉的日常工作是求解：

```
min_x  Σᵢ ‖fᵢ(x)‖²        （x = 位姿/三维点/参数）
```

### 2.1 两大经典算法的直觉

- **高斯–牛顿（Gauss–Newton）**：把残差 f(x) 一阶泰勒展开（本科高数），每步解一个线性最小二乘。收敛快但 JᵀJ 可能奇异。
- **Levenberg–Marquardt（LM）**：`(JᵀJ + λD)δ = −Jᵀr`——λ 大时退化为梯度下降，小时是高斯牛顿：**两大优化流派的内插**，用阻尼项保证矩阵可逆、步长可控。

相关 API：

| 函数 | 优化问题 |
|---|---|
| `cv2.solvePnPRefineLM` / `RefineIterative` | PnP 位姿的 LM 精化（目标函数=重投影误差） |
| `cv2.calibrateCamera` | 光束法平差式的标注重优化（初值来自张正友标定法+LM 精修） |
| `cv2.stereoCalibrate` | 双目标定联合优化 |
| `cv2.findHomography`（LM 精化选项） | 单应矩阵非线性优化 |
| `cv2.phaseCorrelate`、`cv2.findTransformECC` | 图像对齐的牛顿/迭代优化（ECC 最大化=相关系数优化） |
| `cv2.TermCriteria` | 迭代停止准则：容差与最大步数——数值分析语言 |

OpenCV 内置优化器偏保守；研究里常换 **Ceres Solver / g2o** 做完整 BA（Bundle Adjustment：同时优化所有相机位姿与三维点，稀疏结构由射影几何的每帧只连少量点决定）。理解"雅可比矩阵的稀疏块结构"即理解 BA 为什么快。

### 2.2 凸优化：分类与分离的理论地基

线性可分 ⇒ 存在分离超平面；不可分 ⇒ 最小化 hinge 损失。支持向量机 `cv2.ml.SVM_create` 的目标函数：

```
min ½‖w‖² + C·Σξᵢ   s.t.  yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ
```

KKT 条件 ⇒ 对偶问题 ⇒ 核技巧（`cv2.ml.SVM` 的 chi2/线性核，特征匹配 `BFMatcher`+SVM 交叉验证是经典 pipeline）。凸优化的价值：**局部最优=全局最优**，与上面非线性最小二乘的"多局部极小"形成对照。

| 函数 | 优化内容 |
|---|---|
| `cv2.ml.SVM_*` / `NormalBayesClassifier` / `TrainData` | 凸 QP、分类超平面 |
| GrabCut（`cv2.grabCut`） | 图割能量最小化 + GMM，图像分割的组合优化 |
| `cv2.fastNlMeansDenoising` | 加权最小二乘去噪（非凸但闭式） |

## 3. 概率状态估计：跟踪、SLAM 与卡尔曼滤波

硕博阶段把"不确定性"升级为**状态在概率分布上的演化**。

### 3.1 贝叶斯滤波框架

目标跟踪维护状态 xₜ 的后验 p(xₜ|z₁:ₜ)，递推两步：**预测**（运动模型卷积）+ **更新**（贝叶斯公式乘似然）。

- **线性高斯 ⇒ 卡尔曼滤波**：后验保持高斯，均值/协方差的更新有闭式解。`cv2.KalmanFilter` 就是这个：状态转移矩阵 A（射影几何/运动学）、观测矩阵 H（相机投影）、增益 K（由协方差推出）。目标跟踪（`cv2.TrackerKCF` 之外的传统跟踪器、ByteTrack 的卡尔曼部分）核心即它。
- **非线性 ⇒ EKF/UKF**：用泰勒展开（一阶/二阶矩意义）或无迹变换近似——本科篇 2.2 的泰勒公式再次出场。
- **非线性非高斯 ⇒ 粒子滤波（序贯蒙特卡洛）**：大量样本近似后验，大数定律保证收敛。

```python
kf = cv2.KalmanFilter(4, 2)
kf.transitionMatrix = np.array([[1,0,1,0],[0,1,0,1],[0,0,1,0],[0,0,0,1]], np.float32)
kf.measurementMatrix = np.array([[1,0,0,0],[0,1,0,0]], np.float32)
kf.predict(); kf.correct(meas)
```

### 3.2 概率图模型与最大似然

- MOG2 背景建模 = 每像素一个 GMM 的在线 EM 学习（EM=期望最大化的含隐变量极大似然，`cv2.ml.EM` 是其通用实现）。
- `cv2.ml.EM` / `cv2.ml.NormalBayesClassifier`：EM 聚类与降维的另一家。
- 立体匹配 SGBM（`cv2.StereoBM` / `cv2.StereoSGBM`）：代价聚合+路径动态规划，可写成图上的最大后验推断。

## 4. 深度学习数学：`cv2.dnn` 背后的理论

用 ONNX 模型跑 `cv2.dnn.readNet` 推理不需要数学；想改网络、训自己的模型则需要：

- **前向=复合函数求值；反向=链式法则对计算图逐节点应用**。每层的梯度 = 局部雅可比 × 上游梯度（`loss.backward()` 的数学）。卷积层对图像求梯度，正是本科篇"偏导+卷积"的矩阵化（im2col 把卷积写成 GEMM——线代乘法）。
- **优化器**：SGD → 动量 → Adam，是"数值最速下降 + 统计量平滑"；学习率与 batch 大小的关系由梯度的方差解释（大数定律）。
- **信息论**：交叉熵损失 = 负对数似然；Softmax 前的温度与配分函数；KL 散度衡量分布差异（YOLO 用 CIoU 替代则几何味更浓）。
- **泛函/正则化**：权重衰减 = L2 正则 = 贝叶斯先验（高斯先验的 MAP 估计）。Dropout 是近似贝叶斯集成。

| cv2 API | 数学点 |
|---|---|
| `dnn.readNetFromONNX / readNet` | 计算图、张量（高维数组+广播=线代推广） |
| `dnn.NMSBoxes` | 集合覆盖、IoU=交并比（面积测度） |
| `dnn.BlobFromImage` | 仿射变换、均值减法（中心化统计量） |
| YOLO/SSD 解码 | 框回归=坐标参数化（中心/宽高对数尺度） |
| `dnn.TextDetection`/OCR 后处理 | 排序、聚类、四边形拟合 |

## 5. 矩阵计算与数值线性代数（研究级补充）

多视图优化的命门：SVD 在病态数据上的数值行为、正交约束的处理（R 直接优化会离开流形 ⇒ QR/Cayley/Rodrigues 参数化）、稀疏正规方程的 Cholesky 分解（BA 加速）。`cv2.SVDecomp`/`cv2.solve` 在超大规模下常被 Eigen/Ceres 替代。

## 8. 三篇合读：一条公式的成长史

以"旋转"为例回看整条数学链：

1. **高中**：cos/sin 与单位圆 → 会转一张图（`getRotationMatrix2D`）。
2. **本科**：矩阵乘法与正交阵 → 旋转可复合、可求逆；特征值告诉你旋转轴。
3. **硕博**：SO(3) 是流形 → Rodrigues/四元数是坐标卡；优化位姿时**必须**在李代数上更新，否则结果会"漂"出旋转矩阵集合（`calibrateCamera` 内部如此）。

学数学不是为了考试，是为了在 OpenCV 给出离谱结果时，知道该怀疑哪一个假设。祝阅读愉快。
