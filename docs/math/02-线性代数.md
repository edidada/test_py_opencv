# 线性代数：OpenCV 的母语（本科）

> 本科篇·分册 1/4。OpenCV 一半的 API 是矩阵运算，另一半是"解方程/求极值"——后者也建立在线性代数上。读完本篇你能解释：`findHomography` 在解什么方程、`goodFeaturesToTrack` 为什么看特征值、SVD 怎么压缩图像。

## 1. 矩阵就是图像

8 位灰度图 = `H×W` 的 `numpy.uint8` 矩阵；彩色图 = `H×W×3`。`cv2.Mat` 与 `ndarray` 无缝互换：

```python
import cv2, numpy as np
img = cv2.imread("x.png", 0).astype(np.float32)
bright = cv2.add(img, np.full_like(img, 30.0))   # 饱和加，防 uint8 溢出回绕
top    = img[:h//2, :]                            # 子矩阵 = ROI
```

| 线代概念 | OpenCV 函数 | 用途 |
|---|---|---|
| 矩阵乘法 | `matmul` / `@` | 变换复合：M₂·M₁ 一步到位 |
| 逆矩阵 | `invert` | 正变换↔逆变换 |
| 转置 | `transpose` | 换轴、协方差推导 |
| 行列式 | `determinant` | 可否求逆、面积定向 |
| 线性方程组 | `solve` | 正规方程 |
| 迹 | `trace` | 结构张量特征和=梯度能量 |

旋转两次 = 乘一次矩阵（结合律）；相机模型 `P = K·[R|t]` 是矩阵乘法流水线——这两个直觉是后面所有几何内容的地基。

## 2. 投影与最小二乘：OpenCV 的发动机

很多"测量"问题是**超定**的：n 个点拟一条直线，2n 个方程、4 个未知数，无精确解。退而求其次：残差平方和最小。几何语言=把观测向量 **投影** 到 A 的列空间，正交性给出**正规方程**：

```
AᵀA·x = Aᵀb
```

- **`cv2.fitLine`**：点到线垂直距离最小（几何距离 vs 代数距离之分由此而来）。
- **DLT 解单应**：`A·h = 0` 型最小二乘，解=最小奇异值对应的右奇异向量。`cv2.findHomography(src, dst)`：4 对点=8 方程=8 自由度（9 元素模尺度），文档矫正/车牌视角归一化核心；配 `cv2.RANSAC` 剔误匹配。

```python
H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
warped = cv2.perspectiveTransform(pts, H)
```

**数值稳定军规**：像素坐标上千时 `AᵀA` 病态，先归一化到 `[-1,1]²` 再解（Hartley 归一化，`findHomography` 内部自动做）——"先缩放再计算"贯穿数值学科。

## 3. 特征值、二次型与 SVD：从矩阵里"榨"结构

- **特征值** `Av = λv`：变换中方向不变的轴。旋转矩阵的实特征向量=旋转轴；对称阵可正交对角化。
- **结构张量与角点**：`M = Σ [Ix², IxIy; IxIy, Iy²]`（二次型的矩阵！）。Shi–Tomasi `cv2.goodFeaturesToTrack` 取 min(λ₁,λ₂) 大者；Harris `cv2.cornerHarris` 用 λ₁λ₂−k(λ₁+λ₂)²。高中篇"转轴消 Bxy 项"在此兑现为正交对角化。
- **SVD `A = U·S·Vᵀ`**：任何矩阵都可分解。`cv2.SVDecomp`。应用：秩-k 图像压缩、伪逆、PCA、DLT、本质矩阵分解。

```python
img = cv2.imread("lenka.png", 0).astype(np.float32) / 255
u, s, vt = cv2.SVDecomp(img)
low = (u[:, :30] * s[:30].T) @ vt[:30, :]   # 秩-30 近似，奇异值衰减快=能量集中
```

- **PCA**：人脸展平成向量 → 协方差阵 `C = XᵀX/(n−1)` 的特征向量="特征脸"。`cv2.PCATraining` / `cv2.calcPCA`。线代四大概念（基、正交、投影、特征值）的全套演示。
- **`cv2.decomposeProjectionMatrix`**：投影矩阵分离 K、R、t 与相机中心（QR+正交对角化综合应用）。
