# OpenCV 数学 · 高中篇

> 面向只学过高中数学的读者。这一篇就够用到的 OpenCV 功能：旋转、直线/圆检测、椭圆拟合、图像混合、直方图入门。所有例子基于 Python + OpenCV，可直接运行。

先建立一个核心观念：**图像 = 矩阵，像素坐标 = 平面直角坐标系**。OpenCV 的坐标系原点在**左上角**，x 轴向右、y 轴向下——和数学课本里 y 轴向上相反，这会带来一些"旋转方向反了"的小坑，后面会具体讲。

---

## 1. 平面向量：图像的底层语言

### 1.1 复习

向量是有大小和方向的量。两个向量的**数量积（点积）**：

```
a · b = |a||b|cosθ = a.x*b.x + a.y*b.y
```

点积的几何意义：把一个向量"投影"到另一个方向上，值越大越同向，等于 0 说明垂直。

### 1.2 在 OpenCV 里在哪

- **像素本身就是向量**：坐标 `(x, y)` 就是从原点指向这个像素的向量。平移物体就是向量加法：`new = old + (dx, dy)`。
- **彩色像素是三维向量**：BGR 值 `(B, G, R)`。判断两像素颜色是否接近，用的是向量长度（范数）：`‖p1 − p2‖`。
- **`cv2.norm()`**：直接计算两个数组的差的范数，常用于图像差异比较。
- **`cv2.addWeighted()`**：`dst = α·src1 + β·src2 + γ`，就是向量的数乘与加法——图像融合、半透明水印全靠它。

```python
import cv2
import numpy as np

img1 = cv2.imread("a.png")
img2 = cv2.imread("b.png")
blend = cv2.addWeighted(img1, 0.7, img2, 0.3, 0)   # 7:3 混合
diff  = cv2.norm(img1, img2, cv2.NORM_L2)          # 两图"距离"
```

- **模板匹配的直觉**：`cv2.matchTemplate` 在滑动窗口里比较"模板向量"和"窗口向量"的相似程度（差的平方和 / 相关系数）——本质是点积思想的工程化。

## 2. 三角函数：旋转与角度

### 2.1 复习

正弦、余弦描述直角三角形边角关系；单位圆上，角度 θ 对应点 `(cosθ, sinθ)`。两角和公式：

```
cos(α+β) = cosα·cosβ − sinα·sinβ
sin(α+β) = sinα·cosβ + cosα·sinβ
```

### 2.2 旋转矩阵从哪来

把点 `(x, y)` 绕原点逆时针转 θ，用两角和公式展开即得：

```
x' = x·cosθ − y·sinθ
y' = x·sinθ + y·cosθ
```

写成矩阵就是 **旋转矩阵 R(θ)**——这是整个图像几何变换的地基：

```
R = [ cosθ  -sinθ ]
    [ sinθ   cosθ ]
```

### 2.3 在 OpenCV 里在哪

- **`cv2.getRotationMatrix2D(center, angle, scale)`**：内部就是在算上面这个矩阵（平移到 center、旋转、再平移回去）。
- **`cv2.warpAffine`**：拿 2×3 仿射矩阵逐像素搬运。
- **`cv2.minAreaRect`**：返回轮廓的最小外接矩形的"角度"，取值域 `[-90, 0)`，新手常在这里困惑——它来自 `cos/sin` 反解，注意方向约定。

```python
import cv2

img = cv2.imread("card.png")
(h, w) = img.shape[:2]
M = cv2.getRotationMatrix2D((w / 2, h / 2), 30, 1.0)  # 30 度
rotated = cv2.warpAffine(img, M, (w, h))
```

**坑提示**：因为 y 轴向下，`angle` 为**正**时你看到的是"顺时针"旋转的图像，与数学课本的逆时针约定相反。

## 3. 直线方程与直线检测（HoughLines）

### 3.1 复习

直线常见写法：`y = kx + b`（斜截式），或一般式 `Ax + By + C = 0`。

问题：`y = kx + b` 表示不了竖直直线（k 无穷大）。数学家改用**法线式**：

```
x·cosθ + y·sinθ = ρ
```

θ 是原点到直线的垂线与 x 轴的夹角，ρ 是垂线段长度。一条直线由 `(ρ, θ)` 唯一确定。

### 3.2 在 OpenCV 里在哪

- **`cv2.HoughLines` / `cv2.HoughLinesP`**：霍夫直线检测的原理就是把"过某点的所有直线"画在 `(ρ, θ)` 参数空间里——两条这样的曲线求交点，交点 `(ρ, θ)` 就是图像里那条真实的直线。这是高中"方程与曲线"思想最漂亮的一次应用。
- **`cv2.fitLine`**：给一堆点拟合直线，返回单位方向向量 `(vx, vy)` 和直线上一点——方向向量与法向量 `(cosθ, sinθ)` 互为转置。
- 输出 `(rho, theta)` 后画线时要用 `a = cos(theta), b = sin(theta)` 反解回两点式，OpenCV 官方教程的经典代码就是这样。

```python
import cv2
import numpy as np

gray = cv2.cvtColor(cv2.imread("road.png"), cv2.COLOR_BGR2GRAY)
edges = cv2.Canny(gray, 50, 150)
lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=80,
                        minLineLength=60, maxLineGap=8)
for x1, y1, x2, y2 in lines[:, 0]:
    cv2.line(gray, (x1, y1), (x2, y2), (0, 255, 0), 2)
cv2.imshow("lines", gray)
```

参数 `np.pi/180` 就是"θ 以 1 度为步长扫描"——角度制与弧度制的换算 `π rad = 180°` 在这里天天用。

## 4. 圆的方程与圆检测（HoughCircles）

### 4.1 复习

圆心 `(a, b)`、半径 r 的圆：`(x−a)² + (y−b)² = r²`。展开成 `x² + y² + Dx + Ey + F = 0` 说明确定一个圆需要 **3 个参数**——对应霍夫空间需要三维累加器。

### 4.2 在 OpenCV 里在哪

- **`cv2.HoughCircles`**：边缘像素 (x, y) 在每个方向上"距离 r 处都可能是圆心"，把这些候选圆心在参数空间里投票，票数峰值即检测结果。为了加速，实际用"先投票圆心、再投票半径"的分策略（Hough Gradient 法）。
- **`cv2.minEnclosingCircle`**：给一组点求最小覆盖圆，返回圆心和半径。
- **Blob 检测、瞳孔检测**（眼睛虹膜近似圆）都是它的下游应用。

```python
import cv2
import numpy as np

gray = cv2.cvtColor(cv2.imread("coins.png"), cv2.COLOR_BGR2GRAY)
gray = cv2.medianBlur(gray, 5)
circles = cv2.HoughCircles(gray, cv2.HOUGH_GRADIENT, dp=1,
                           minDist=30, param1=100, param2=30,
                           minRadius=10, maxRadius=50)
for x, y, r in circles[0]:
    cv2.circle(gray, (int(x), int(y)), int(r), (0, 255, 0), 2)
```

`minRadius/maxRadius`、`param2`（投票阈值）的直觉全来自"圆由三个参数决定"这一句话。

## 5. 圆锥曲线：椭圆与 `fitEllipse`

### 5.1 复习

椭圆定义：到两定点距离之和为常数。标准方程 `x²/a² + y²/b² = 1`。一般位置的椭圆（带旋转）展开后是二次方程：

```
Ax² + Bxy + Cy² + Dx + Ey + F = 0   （满足 B² − 4AC < 0）
```

共 5 个独立参数 ⇒ 至少 5 个点可以确定一个椭圆。

### 5.2 在 OpenCV 里在哪

- **`cv2.fitEllipse(points)`**：输入轮廓点，返回 `((cx, cy), (MA, ma), angle)`——中心、长短轴、倾角。倾角 `angle` 就是椭圆相对坐标轴的旋转量，正是"一般二次方程"和"标准方程"之间的桥梁（旋转坐标轴可消去 Bxy 项——这个"转轴消项"的思想在硕博篇的正交对角化里会再现）。
- 应用：倾斜的硬币/车牌/零件检测。旋转矩形 `minAreaRect` 与 `fitEllipse` 常配合定位倾斜目标。

```python
import cv2
import numpy as np

img = cv2.imread("coin.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, bw = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
contours, _ = cv2.findContours(bw, cv2.RETR_EXTERNAL,
                               cv2.CHAIN_APPROX_SIMPLE)
ellipse = cv2.fitEllipse(contours[0])
cv2.ellipse(img, ellipse, (0, 0, 255), 2)
print(ellipse)  # ((cx, cy), (长轴, 短轴), 倾角)
```

## 6. 数列与求和：直方图、卷积的雏形

### 6.1 复习

求和符号 `Σ`：`Σ f(i)`，i 从 1 到 n。等差/等比数列求和。

### 6.2 在 OpenCV 里在哪

- **直方图 = 频数求和**：`cv2.calcHist` 统计每个灰度级出现的次数，满足 `Σ hist[i] = 像素总数`。`cv2.equalizeHist`（直方图均衡化）的本质：把每个灰度级映射到它的**累加和**（累积分布），拉开压缩的对比度——这是"数列前缀和"的直接应用。
- **卷积 = 加权求和**：3×3 核在图像上滑动，每个输出像素是邻域 9 个值乘以核权重再求和，即 `Σ Σ k(i,j)·img(x+i, y+j)`。模糊、锐化、边缘检测全是这一个公式，只是权重不同。
- **均值与最值**：`cv2.mean`、`cv2.meanStdDev` 里的平均就是 `Σx/n`。

```python
import cv2

img = cv2.imread("low_contrast.png", cv2.IMREAD_GRAYSCALE)
eq = cv2.equalizeHist(img)     # 累加和归一化后重映射灰度

blur = cv2.blur(img, (3, 3))   # 核权重全为 1/9 的卷积
```

## 7. 概率初步：噪声从哪来

### 7.1 复习

古典概型、频率与概率、简单的随机抽样。

### 7.2 在 OpenCV 里在哪

- **传感器噪声**：暗光下拍照，每个像素的值是"真实值 + 随机扰动"。理解"扰动有大有小、小的更常见"，就能理解高斯模糊为什么能压噪声、为什么又会糊细节（本科篇用正态分布量化它）。
- **随机抽样**：RANSAC 的思想——从数据里随机抽最少的点（两点定线、三点定圆，正是本文档第 3、4 节的结论）建立模型，看多少点"同意"这个模型。`cv2.findFundamentalMat(..., cv2.FM_RANSAC)` 底层就是这个高中级别的直觉。
