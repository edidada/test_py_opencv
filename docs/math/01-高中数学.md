## 0. 开胃：图像在计算机里到底是什么

```python
import cv2
import numpy as np

img = cv2.imread("photo.png")        # 读入：BGR 三通道矩阵
print(img.shape)                     # (高 H, 宽 W, 3)
px = img[100, 200]                   # 第 100 行、第 200 列像素的 B,G,R
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)  # 加权平均转灰度
cv2.imshow("win", img)               # 显示
cv2.imwrite("out.jpg", img)          # 写出
```

- 灰度图像 = 一个数表，每个位置 (x, y) 对应一个 0~255 的整数。**0 是黑，255 是白**。
- 彩色 = 三个数表叠起来（OpenCV 用 BGR 顺序，不是 RGB——保存时颜色反了就是这个原因）。
- `cv2.cvtColor` 转灰度用的公式是 `gray = 0.299R + 0.587G + 0.114B`——人眼对绿色最敏感所以权重最大。这就是高中"加权平均"的生活应用。

## 1. 平面向量：图像的底层语言

### 1.1 复习

向量是有大小和方向的量。加减法满足平行四边形法则；数乘 `λa` 伸缩方向。两个向量的**数量积（点积）**：

```
a · b = |a||b|cosθ = a.x*b.x + a.y*b.y
```

点积的几何意义：把一个向量"投影"到另一个方向上，值越大越同向，等于 0 说明垂直。两向量夹角公式：`cosθ = (a·b)/(|a||b|)`——注意分母那个"模长" `|a| = √(a.x²+a.y²)`，就是勾股定理。

### 1.2 在 OpenCV 里在哪

- **像素坐标本身就是向量**：`(x, y)` 是从原点指向这个像素的向量。平移物体 = 向量加法 `new = old + (dx, dy)`，对应 `cv2.warpAffine` 的平移分量。
- **彩色像素是三维向量**：BGR 值 `(B, G, R)`。判断两像素颜色是否接近用向量模长：`‖p1 − p2‖`（欧氏距离，勾股定理的三维版）。
- **`cv2.norm()`**：计算两个数组差的范数，图像差异比较、算法误差评估天天用。
- **`cv2.addWeighted()`**：`dst = α·src1 + β·src2 + γ`，向量的数乘+加法——图像融合、半透明水印、双曝光效果全靠它。
- **点积的隐形出场**：模板匹配 `cv2.matchTemplate` 的"相关系数法"（TM_CCORR_NORMED）本质是滑动窗口里两个"颜色向量"的夹角余弦——越接近 1 越像。

```python
import cv2
import numpy as np

img1 = cv2.imread("a.png")
img2 = cv2.imread("b.png")
blend = cv2.addWeighted(img1, 0.7, img2, 0.3, 0)   # 7:3 混合
diff  = cv2.norm(img1, img2, cv2.NORM_L2)          # 两图"距离"
mask  = cv2.matchTemplate(img1, img2[50:100, 50:100],
                          cv2.TM_CCOEFF_NORMED)    # 找相似区域
```

### 1.3 绝对值与不等式：阈值和范数的语言

`|x| < 5` 表示"x 落在 (-5, 5)"。图像领域到处是这种"距离小于某值就算相等"的判断：二值化 `if pixel > t`、颜色容差 `inRange`、匹配得分阈值。理解绝对值不等式，就理解了为什么"阈值"这个参数如此关键——它划定了"算不算"的边界。

```python
mask = cv2.inRange(hsv, np.array([0, 120, 100]),
                        np.array([10, 255, 255]))  # HSV 三个分量都在区间内 → 255
```

## 2. 三角函数：旋转与角度

### 2.1 复习

单位圆定义：角度 θ 对应圆上点 `(cosθ, sinθ)`。弧度制 `π rad = 180°`。两角和公式：

```
cos(α+β) = cosα·cosβ − sinα·sinβ
sin(α+β) = sinα·cosβ + cosα·sinβ
```

诱导公式与周期性：`sin(θ+2π)=sinθ`——旋转 360° 回到原位的数学表达。

### 2.2 旋转矩阵从哪来

把点 `(x, y)` 绕原点逆时针转 θ。用极坐标写 `x = r·cosφ, y = r·sinφ`，转后角度变为 φ+θ，用两角和公式展开：

```
x' = r·cos(φ+θ) = x·cosθ − y·sinθ
y' = r·sin(φ+θ) = x·sinθ + y·cosθ
```

写成矩阵就是 **旋转矩阵 R(θ)**——整个图像几何变换的地基：

```
R = [ cosθ  -sinθ ]
    [ sinθ   cosθ ]
```

它保长度、保角度（正交变换的高中名字：刚体旋转）。

### 2.3 在 OpenCV 里在哪

- **`cv2.getRotationMatrix2D(center, angle, scale)`**：内部就在算上面这个矩阵（先平移到 center、旋转、再平移回去）。
- **`cv2.warpAffine`**：拿 2×3 仿射矩阵逐像素搬运。
- **解三角形**：测距场景——已知像素尺寸与实际尺寸的比例（相似三角形），从图像量出"物体占多少像素"即可换算实际长度；需要 `sin/cos` 与正余弦定理。
- **`cv2.minAreaRect`** 返回的"角度"新手常困惑：取值约定与 y 轴向下叠加，方向看起来"反"，本质仍是 cos/sin 反解。

```python
import cv2

img = cv2.imread("card.png")
(h, w) = img.shape[:2]
M = cv2.getRotationMatrix2D((w / 2, h / 2), 30, 1.0)  # 30 度
rotated = cv2.warpAffine(img, M, (w, h))
```

**坑提示**：因为 y 轴向下，`angle` 为**正**时图像**顺时针**转，与课本逆时针约定相反。Hough 检测里 θ 用弧度，`np.pi/180` 一度一度扫，弧度制与角度制换算每天都在用。

## 3. 直线方程与直线检测（HoughLines）

### 3.1 复习

直线常见写法：`y = kx + b`（斜截式）、`Ax + By + C = 0`（一般式）、两点式、截距式。问题：`y = kx + b` 表示不了竖直直线（k 不存在）。数学家改用**法线式**：

```
x·cosθ + y·sinθ = ρ
```

θ 是原点到直线的垂线与 x 轴的夹角，ρ 是垂线段长度。一条直线由 `(ρ, θ)` 唯一确定（θ∈[0,2π)）。两条直线交点 = 联立方程组求解；点到直线距离 `d = |Ax₀+By₀+C| / √(A²+B²)`——向量投影的直接应用。

### 3.2 在 OpenCV 里在哪

- **`cv2.HoughLines` / `cv2.HoughLinesP`**：霍夫变换原理就是把"过某点的所有直线"画在 `(ρ, θ)` 参数空间里——图像上一个点对应参数空间一条正弦曲线；两条曲线求交点，交点 `(ρ, θ)` 就是同时"穿过"两个图像点的那条真实直线。大量边缘点在同一条线上 ⇒ 它们的正弦曲线共点 ⇒ 投票峰值。这是高中"方程 ↔ 曲线"对应思想最漂亮的一次应用。
- **`cv2.fitLine`**：给一堆点拟合直线，返回单位方向向量 `(vx, vy)` 和直线上一点。
- 检测结果画线时需要从 `(ρ, θ)` 反解：取 `a=cosθ, b=sinθ`，线上两点 `(aρ + 1000·(-b), bρ + 1000·a)` 与 `(aρ - 1000·(-b), bρ - 1000·a)`——即找垂足再沿方向走 1000 像素。

```python
import cv2
import numpy as np

gray = cv2.cvtColor(cv2.imread("road.png"), cv2.COLOR_BGR2GRAY)
edges = cv2.Canny(gray, 50, 150)
lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=80,
                        minLineLength=60, maxLineGap=8)
for x1, y1, x2, y2 in lines[:, 0]:
    cv2.line(gray, (x1, y1), (x2, y2), (0, 255, 0), 2)
cv2.imshow("lines", gray)
```

## 4. 圆的方程与圆检测（HoughCircles）

### 4.1 复习

圆心 `(a, b)`、半径 r 的圆：`(x−a)² + (y−b)² = r²`；展开为 `x² + y² + Dx + Ey + F = 0` 说明确定一个圆需要 **3 个参数**（对应霍夫空间需要三维累加器）。两圆位置关系（相交/相切/相离）由圆心距与半径和差比较——初中平面几何，如今是**模板重叠、圆形目标去重**的判断依据。直线与圆相切 ⇔ 圆心到直线距离 = r：Canny 边缘法向的来历。

### 4.2 在 OpenCV 里在哪

- **`cv2.HoughCircles`**：边缘像素处"圆心可能在沿法向距离 r 的位置"，在参数空间投票；实际用 Hough Gradient 加速策略（先投圆心，再由边缘方向反推半径候选）。
- **`cv2.minEnclosingCircle`**：给一组点求最小覆盖圆，返回圆心和半径。
- 应用：硬币计数、瞳孔定位（虹膜近似圆）、交通标志检测。

```python
import cv2
import numpy as np

gray = cv2.cvtColor(cv2.imread("coins.png"), cv2.COLOR_BGR2GRAY)
gray = cv2.medianBlur(gray, 5)
circles = cv2.HoughCircles(gray, cv2.HOUGH_GRADIENT, dp=1,
                           minDist=30, param1=100, param2=30,
                           minRadius=10, maxRadius=50)
for x, y, r in circles[0]:
    cv2.circle(gray, (int(x), int(y)), int(r), (0, 255, 0), 2)
```

`minRadius/maxRadius` 限定第三维投票范围，`param2` 是投票阈值——直觉全部来自"圆由三个参数决定"。

## 5. 圆锥曲线：椭圆与 `fitEllipse`

### 5.1 复习

椭圆定义：到两定点距离之和为常数。标准方程 `x²/a² + y²/b² = 1`，离心率 `e = c/a` 描述"扁"的程度。一般位置（带旋转）的椭圆展开是二次方程：

```
Ax² + Bxy + Cy² + Dx + Ey + F = 0   （B² − 4AC < 0）
```

5 个独立参数 ⇒ 至少 5 个点确定一个椭圆。抛物线、双曲线是同一族方程的兄弟（`B²−4AC = 0 / > 0`），OpenCV 里 `cv2.fitEllipse` 的判别思路同源。"转轴消 Bxy 项"（把旋转椭圆变回标准形）这个操作，到本科会变成特征值对角化——先埋个伏笔。

### 5.2 在 OpenCV 里在哪

- **`cv2.fitEllipse(points)`**：输入轮廓点，返回 `((cx, cy), (MA, ma), angle)`——中心、长短轴、倾角。倾角就是"椭圆相对坐标轴转了多少"，正对应上面的坐标旋转消项。
- 应用：倾斜硬币/车牌/工业零件定位。常与 `cv2.minAreaRect`（旋转矩形）配合。

```python
import cv2

img = cv2.imread("coin.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, bw = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
contours, _ = cv2.findContours(bw, cv2.RETR_EXTERNAL,
                               cv2.CHAIN_APPROX_SIMPLE)
ellipse = cv2.fitEllipse(contours[0])
cv2.ellipse(img, ellipse, (0, 0, 255), 2)
print(ellipse)  # ((cx, cy), (长轴, 短轴), 倾角)
```

顺带两条高中公式的 OpenCV 版：**弧长**——多边形近似 `cv2.arcLength` 把曲线切成小段折线求和（极限思想，本科篇积分的前身）；**面积**——`cv2.contourArea` 用鞋带公式（坐标交叉相乘求差），本质是"把不规则图形拆成三角形"的推广。

## 6. 函数与图像变换：灰度曲线（LUT）

### 6.1 复习

函数 y = f(x) 的图像平移、伸缩、对称：`f(x)+k` 上下移、`a·f(x)` 纵缩、`f(-x)` 关于 y 轴对称。复合函数 `f(g(x))`。

### 6.2 在 OpenCV 里在哪

把"像素值→新像素值"看成一元函数：

- **亮度/对比度**：`g = a·f + b`（a 是斜率=对比度，b 是截距=亮度）。
- **反色**：`255 − f`；**二值化**：分段函数 `f>t ? 255 : 0`。
- **Gamma 校正**：`g = 255·(f/255)^γ`——幂函数家族。γ<1 提亮暗部，γ>1 压暗。手机夜景的"自动亮度曲线"就是它。
- **`cv2.LUT` / `cv2.convertScaleAbs`**：任意灰度曲线都存成 256 项查表——函数图像离散化。

```python
import cv2
import numpy as np

img = cv2.imread("dark.png")
gamma = 0.45
table = np.array([255 * (i / 255) ** gamma for i in range(256)],
                 dtype=np.uint8)
bright = cv2.LUT(img, table)                    # 幂函数曲线提亮
linear = cv2.convertScaleAbs(img, alpha=1.3, beta=10)  # 一次函数调对比
```

## 7. 数列与求和：直方图、卷积的雏形

### 7.1 复习

求和符号 `Σ`，等差/等比数列求和，前缀和 `Sₙ`，极限思想（无穷逐项逼近）。

### 7.2 在 OpenCV 里在哪

- **直方图 = 频数统计**：`cv2.calcHist` 统计每个灰度级出现次数，`Σ hist[i] = 像素总数`。
- **直方图均衡化 = 前缀和重映射**：`cv2.equalizeHist` 把灰度 g 映到它的累积和 `S(g)/N·255`——把挤在一起的分布"拉匀"，逆光照片救星。
- **卷积 = 加权求和**：输出像素 = `Σ Σ k(i,j)·img(x+i, y+j)`。模糊（权重全正）、锐化（中心正大、四周负）、浮雕（不对称权重）只是权重不同。
- **极限/迭代**：形态学开闭运算重复执行会收敛；"迭代到不再变化"在 OpenCV 到处都是（迭代式阈值、平滑）。

```python
import cv2

img = cv2.imread("backlit.png", cv2.IMREAD_GRAYSCALE)
eq = cv2.equalizeHist(img)          # 累加和归一化后重映射灰度
blur = cv2.blur(img, (3, 3))        # 核权重全为 1/9 的加权求和
```

## 8. 概率初步：噪声、抽样与 RANSAC 直觉

### 8.1 复习

古典概型、频率估计概率、随机抽样、独立事件乘法。

### 8.2 在 OpenCV 里在哪

- **传感器噪声**：暗光下每个像素 = 真实值 + 随机扰动。"扰动有大有小、小的更常见"的直觉就能理解中值滤波为什么既能压椒盐噪声又保边缘（`cv2.medianBlur` 取邻域中位数——统计学里"中位数比平均数抗离群值"）。
- **随机抽样**：RANSAC 思想——随机抽"刚好确定模型"的最少点（两点定线、三点定圆、四点定单应，全是本篇第 3–5 节的结论），看多少点"同意"这个模型（内点数），重复多次取最优。`cv2.findFundamentalMat(..., cv2.FM_RANSAC)`、`cv2.estimateAffinePartial2D(..., cv2.RANSAC)` 底层就是它。
- **几何概型**：随机撒点估计面积/比例——蒙特卡洛方法的第一课。

```python
import cv2
import numpy as np

src = cv2.imread("scene.png")
noisy = cv2.add(src, np.random.randint(-40, 40, src.shape, dtype=np.int8).astype(np.uint8))
clean = cv2.medianBlur(noisy, 3)     # 中位数抗离群值
```

## 9. 立体几何与空间向量的预告

高二空间向量（坐标化、点积求夹角、叉积求法向量）是理解"相机在三维空间里的姿态（旋转+平移）"的预备知识。`cv2.solvePnP`、`cv2.Rodrigues` 的直觉——"物体相对相机转了多少、离了多少"——到本科（矩阵）与硕博（射影几何）才完全展开。选必修第一册的空间向量章节值得认真学，它决定了你日后看 3D 视觉论文会不会晕。
