# 概率论与数理统计：噪声、滤波与阈值（本科）

> 本科篇·分册 3/4。图像处理的另一半灵魂是统计：噪声是随机变量，滤波是最优估计，阈值是判别问题，直方图是分布的频率估计。

## 1. 正态分布 → 高斯模糊与噪声建模

**`cv2.GaussianBlur` / `cv2.getGaussianKernel`**：核 `g(x) ∝ exp(−x²/2σ²)`。为什么是高斯？噪声常建模为高斯白噪声（独立同分布、方差 σ²），均方误差最小的线性滤波的最优核恰是高斯形。工程换算 `ksize ≈ 6σ+1` 来自"正态变量落 ±3σ 外概率约 0.27%"。

常见噪声模型：

| 噪声 | 分布特征 | 对症滤波 |
|---|---|---|
| 高斯 | 小幅高频扰动为主 | 高斯模糊/非局部均值 |
| 椒盐 | 以概率 p 取 0 或 255 | **中值** `cv2.medianBlur`（中位数比均值抗离群值） |
| 泊松 | 光子计数，σ²∝μ（暗区更噪） | 先平方根变换再滤波，RAW 处理常识 |

## 2. 期望、方差 → Otsu 自动阈值

`cv2.threshold(..., cv2.THRESH_OTSU)`：遍历候选 t，把像素分两类，最大化**类间方差**

```
σ²(t) = ω₀ω₁(μ₀ − μ₁)²
```

只用期望与方差定义——《概率论》第二章的直接应用，也是"判别准则"思想第一课。同类统计量：`cv2.meanStdDev`（均值/标准差）；PSNR `10·log₁₀(MAX²/MSE)`=噪声方差的 dB 表达。

## 3. 大数定律与直方图

直方图 = 概率分布的频率估计（样本越多越接近真分布）。
- `cv2.equalizeHist`：CDF 变换把经验分布整形成均匀分布（概率积分变元的离散版）。
- `cv2.compareHist`：巴氏距离/相关系数=比较两个经验分布。
- `cv2.calcBackProject`：用直方图反投影做目标概率图——贝叶斯味的跟踪基础。

## 4. 贝叶斯公式 → 背景建模与分类

`p(前景|颜色) ∝ p(颜色|前景)·p(前景)`。

- **`cv2.createBackgroundSubtractorMOG2`**：每像素一个高斯混合模型拟合历史，当前值似然低 ⇒ 前景。
- **`cv2.ml.NormalBayesClassifier`**：朴素贝叶斯（特征条件独立假设）的显式实现。

## 5. 参数估计：MLE、矩估计与 EM

- **矩估计**：直方图均值/方差反推噪声 σ ⇒ `cv2.fastNlMeansDenoising` 的 h 参数标定经验。
- **`cv2.ml.EM`**：含隐变量的极大似然——E 步求后验分配、M 步重估参数，似然单调上升的坐标上升；GMM 学习的标准解法。
