## 为什么 OpenCV 需要数学？

一张数字图像在程序里就是一个**二维数组（矩阵）**：灰度图是 `H×W` 的矩阵，彩色图是 `H×W×3` 的三个矩阵叠在一起。于是：

- 图像操作 = 矩阵运算（加法、卷积、求逆、分解）
- 几何变换 = 坐标乘以变换矩阵（旋转、缩放、透视）
- 识别与测量 = 在数据里拟合模型（拟合直线、拟合椭圆、优化重投影误差）
- 去噪与增强 = 概率与统计（噪声建模、滤波、阈值）

不懂数学也能调 API，但遇到"结果不对"时，只有数学能告诉你是参数错了还是模型错了。

## 建议学习路径

1. **只会高中数学**：读 [01]，就能理解旋转、霍夫检测、椭圆拟合、灰度曲线这些"几何与函数类"功能。
2. **本科在读或想补**：[02] 线性代数 + [03] 高数覆盖 OpenCV 80% 的 API；[04] 统计管去噪与阈值；[05] 数值分析解释所有"插值/容差/迭代"参数。
3. **做标定、三维重建、SLAM、深度学习**：按 [06] 多视图 → [07] 优化 → [08] 凸优化/图模型 → [09] 状态估计 → [10] 深度学习的顺序推进。
