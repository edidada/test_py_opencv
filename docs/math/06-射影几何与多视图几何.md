# 射影几何与多视图几何：相机如何书写三维世界（硕博）

> 硕博篇·分册 1/5。这是计算机视觉方向的学位课核心：标定、三维重建、视觉里程计、SLAM 全部建立在射影几何之上。教材是 Hartley & Zisserman 的"多视图几何圣经"。

## 1. 针孔模型与齐次坐标：把除法藏进矩阵

相似三角形给出投影 `x = f·X/Z, y = f·Y/Z`。除法非线性，矩阵写不下。射影几何的解法：**给坐标加一维**，且 `(λX, λY, λZ, λ) ≡ (X, Y, Z)`：

```
s·[u, v, 1]ᵀ = K · [R | t] · [X, Y, Z, 1]ᵀ
```

- `s`：齐次尺度（=深度 Z 的化身，`1/Z` 透视缩形的代数根源）；
- `K = [fx 0 cx; 0 fy cy; 0 0 1]`：内参（焦距+主点）；
- `[R|t]`：外参（世界系→相机系）。

**三维→二维 = 一个 3×4 矩阵乘法**。`cv2.calibrateCamera` 返回的 cameraMatrix/rvecs/tvecs 就是这套参数；`cv2.projectPoints` 是它的执行器。

射影几何回答的工程问题：
- **4 点定单应**：射影变换 8 自由度（9 元素模尺度），每点 2 方程。
- **灭点**：铁轨照片平行线相交——无穷远点（w=0）映射为有限像点；`cv2.decomposeProjectionMatrix` 的相机中心=零空间向量。
- **绝对二次曲线与自标定**：圆环点隐含在 Ω∞ 中，"找让 Ω∞ 变圆的线"=Zhang 标定的几何本质。

## 2. 畸变模型：多项式为什么长那样

真实镜头≠针孔。径向畸变用幂级数近似：

```
x_d = x(1 + k₁r² + k₂r⁴ + k₃r⁶)，y_d 同理 + 切向项 p₁, p₂
```

"光滑映射局部可用多项式逼近"（泰勒思想再出场）。鱼眼换等距投影 `θ = w·r`（`cv2.fisheye` 模块）。矫正=反向映射：`cv2.undistort` / `initUndistortRectifyMap` + `remap`。

## 3. 对极几何：两台相机之间的免费约束

两相机看同一场景，对应点被约束在**极线**上——不需要任何先验的三维重建起点：

```
x₂ᵀ · F · x₁ = 0     （基础矩阵 F，像素坐标版，7 自由度）
F = K₂⁻ᵀ · E · K₁⁻¹，  E = [t]ₓ·R（本质矩阵，内参已知）
```

| 函数 | 数学内容 |
|---|---|
| `cv2.findFundamentalMat` | 对极约束线性解（8 点法）/非线性（7 点法）+ RANSAC |
| `cv2.findEssentialMat` | E 的 5 点法（多项式求根，Stewenius/Nister） |
| `cv2.recoverPose` | E 的 SVD 分解出 4 组 (R,t)，"点在两相机前方"消歧 |
| `cv2.triangulatePoints` | 两射线最近点=线性最小二乘（齐次 DLT） |
| `cv2.stereoRectify` | 相似变换使极线水平对齐 |
| `cv2.reprojectImageTo3D` | 视差 d → 深度 Z = f·B/d |
| `cv2.computeCorrespondEpilines` | 由 F 预测极线（匹配搜索域降 1 维） |

```python
E, mask = cv2.findEssentialMat(p1, p2, K, method=cv2.FM_RANSAC)
_, R, t, _ = cv2.recoverPose(E, p1, p2, K)
pts4 = cv2.triangulatePoints(P1, P2, p1[:2], p2[:2])
X = (pts4[:3] / pts4[3]).T
```

**P3P/EPnP**（`cv2.solvePnP` 的方法参数）：已知 3D-2D 对应，P3P=3 点+1 参考点闭式解（解多项式方程组，至多 4 解）；EPnP=把 3D 点写成 4 控制点的凸组合（重心坐标），4 点即解。计算几何+线性代数的组合技巧。

## 4. 章末速查与习题式自测

| 想做的事 | 用到的 API 链 |
|---|---|
| 单帧文档矫正 | `findHomography`（8 自由度）→ `warpPerspective` |
| 两帧相对位姿 | `findEssentialMat` → `recoverPose` |
| 稀疏重建 | `triangulatePoints` → 点云 |
| 深度图 | `StereoSGBM` → `reprojectImageTo3D` |
| 已知 3D 模型测位姿（AR） | `solvePnP`(P3P/EPnP) + `solvePnPRansac` |
| 相机内参标定 | `calibrateCamera`（张正友法） |

自测：为什么 8 点法求 F 是线性问题而 7 点法是非线性？（F 有 7 自由度，7 点恰好列 7 方程，需强制 det F=0 的秩约束 ⇒ 多项式组多解。）
