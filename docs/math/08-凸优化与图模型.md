# 凸优化与图模型：可全局求解的那一类问题（硕博）

> 硕博篇·分册 3/5。与 LM 的"局部最优"相对照：凸问题保证全局最优；图模型把"像素/标签之间的相互约束"写成可推断的结构。SVM、GrabCut、CRF 精修都属此家族。

## 1. 凸优化：SVM 为什么能"一解到底"

凸集上的凸函数，局部最优=全局最优。支持向量机的原始问题：

```
min ½‖w‖² + C·Σξᵢ   s.t.  yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ
```

- **对偶化**（拉格朗日乘子、KKT 条件）⇒ 最优解只依赖内积 ⇒ 特征"支持向量化"，名字由此而来；
- **核技巧**：内积换核函数 ⇒ 线性不可分变高维可分（`cv2.ml.SVM` 的 LINEAR/RBF/CHI2 核）。

| 函数 | 数学点 |
|---|---|
| `cv2.ml.SVM` / `LogisticRegression` / `NormalBayesClassifier` | 凸 QP、对偶、核技巧 |
| `cv2.ml.EM` | 隐变量极大似然的坐标上升（非凸但有单调保证） |
| `cv2.fastNlMeansDenoising` | 由相似度加权的核回归（非参数统计视角） |

对偶、KKT、内点法是《凸优化》教材的核心；Boyd 官网免费 PDF，纸质中译本 ISBN 见下表。

## 2. 图割：图像分割的组合优化

二值分割能量 E(标签)=数据项+平滑项，满足子模条件时可写成**最小割**精确求解——最大流最小割定理是对偶定理在离散域的孪生：

- **`cv2.grabCut`**：前景/背景各一个 GMM（数据项）+ 像素间 Potts 平滑（图割项），迭代"估 GMM → 图割 → 再估"。
- **`cv2.watershed`**：形态学测地距离——偏微分方程视角的"每条盆地的最短路径"。
- **CRF 精修**（`cv2.ximgproc.createJointBundleAdjustment` 之外的 `cv2.ximgproc.createBCNN`/DenseCRF）：条件随机场把分割边界"吸附"到颜色不连续处，推断用均值场（变分框架）。

## 3. 概率图模型的语言（承上启下）

- 随机场=变量集合+邻接结构；能量最小化=最大后验（MAP）。
- 链/树结构⇒动态规划精确推断（立体匹配 SGBM 的 8/16 路径代价聚合=链上 MAP；"路径=图结构，DP=推断"）。
- 一般图⇒近似推断：置信传播/均值场/图割。Bishop PRML 第 8 章是系统入门。
