# 深度学习数学：`cv2.dnn` 背后的理论（硕博）

> 硕博篇·分册 5/5。推理不需要数学，训练和改造需要。反向传播=链式法则，损失=似然，正则化=先验，注意力=加权平均——本篇把"花书"里真正落地到 CV 工程的公式逐条点名。

## 1. 前向是复合函数，反向是动态规划

- 网络 = 逐层复合 f_L∘…∘f₁；**反向传播 = 链式法则在计算图上的逐节点应用**：每层梯度 = 局部雅可比 × 上游梯度（`loss.backward()` 的数学）。
- 卷积层对图像求梯度 = 一次转置卷积——本科篇"偏导+卷积"的矩阵化。
- **im2col** 把卷积摊成 GEMM（矩阵乘）——为什么 GPU 对 CNN 利用率那么高：因为那就是一场矩阵乘法大会。
- ResNet 残差块 = 恒等映射 + 扰动：梯度直通公式 `∂(x+F(x))/∂x = I + ∂F/∂x`，解释深网可训练性。

## 2. 损失与 Softmax 的漂亮相消

```
softmax:  pᵢ = e^{zᵢ}/Σe^{zⱼ}
交叉熵:   L = −log p_true
梯度:     ∂L/∂z = p − y（预测减真值）
```

对数似然 × 指数族的一阶导数练习——分类损失梯度如此干净的原因。检测里：框回归=坐标参数化（中心点 + **对数宽高**，保证尺度不变），YOLO 的 CIoU 则完全是几何测度（IoU=交并比=面积测度）。`cv2.dnn.NMSBoxes` 做的是集合覆盖式去重。

## 3. 优化器谱系：SGD → 动量 → Adam

- 小 batch 梯度是真梯度的**无偏估计**（大数定律控制方差）；
- 动量 = 梯度一阶 EMA；Adam = 一阶+二阶 EMA + 偏差修正；
- 学习率调度 = 非凸地形上的步长策略（对应凸优化里线搜索的随机化版本）。
- BatchNorm = 重新参数化让优化地形条件更好（"凸性视角的坐标变换"，与本科篇"先归一化再计算"同构）。

## 4. 正则化 = 贝叶斯先验

- L2 权重衰减 ⇔ 高斯先验的 **MAP** 估计；L1 ⇔ 拉普拉斯先验 ⇒ 稀疏。
- Dropout ⇔ 近似贝叶斯集成（训练=采样子网络求和）。
- 早停 ⇔ 隐含先验的约束。
——"防止过拟合"的工程口诀，每条都有概率统计的对偶解释。

## 5. `cv2.dnn` 侧的对应

| cv2 API | 数学点 |
|---|---|
| `dnn.readNetFromONNX` / `readNet` / `Net.forward` | 计算图、张量（高维数组+广播=线代推广） |
| `dnn.BlobFromImage` | 均值减法（中心化）、尺度归一（标准化） |
| `dnn.NMSBoxes` | 集合覆盖、IoU 面积测度 |
| YOLO/SSD 解码 | 对数宽高回归、锚框参数化 |
| `dnn.text` / `ocr` 后处理 | CTC 贪心解码=序列对齐动态规划 |
| 注意力层（Transformer 模型） | `softmax(QKᵀ/√d)V` = 按相似度加权取值——高中加权平均+点积的深度学习版 |

## 6. 章末自测

1. 为什么交叉熵+Softmax 的梯度是 p−y？（对数求导+配分函数一阶导。）
