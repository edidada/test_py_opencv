# 高等数学与傅里叶分析：导数、积分与频率（本科）

> 本科篇·分册 2/4。边缘检测=求导，图像质量=积分与矩，去摩尔纹=频域滤波。这一册把《高等数学》上下册里真正被 OpenCV 用到的章节全部点名。

## 1. 偏导数 → 图像梯度 → 边缘

图像是二元函数 f(x,y)=灰度，**边缘 = 灰度突变 = 梯度**：

```
∇f = (∂f/∂x, ∂f/∂y)   —— 垂直等值线（边缘），指向增长最快方向
```

离散世界用差分近似导数（`(f(x+1)−f(x−1))/2` 的卷积形式）：

- **`cv2.Sobel` / `cv2.Scharr`**：一/二阶偏导核；Scharr 的 3×3 核旋转对称性更好（各向同性误差更小）。
- **`cv2.Canny`**：梯度幅值+方向 → 非极大值抑制（沿梯度方向比较只留脊线）→ 双阈值滞后连接，每一步都是导数语言。
- **方向导数 = ∇f·u**：解释 Sobel 的 x/y 分量如何合成任意方向响应。

```python
gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)   # ∂f/∂x
gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)   # ∂f/∂y
mag = cv2.magnitude(gx, gy)                        # |∇f|
```

## 2. 泰勒展开 → 光流约束方程

`cv2.calcOpticalFlowPyrLK`（Lucas–Kanade）核心一步：对 `I(x+dx, y+dy, t+dt)` 一阶泰勒展开，令亮度恒定：

```
Iₓ·dx + I_y·dy = −I_t
```

一个方程两个未知数 ⇒ 窗口内 25 像素联立 + 最小二乘解 `(dx, dy)`，迭代（牛顿法思想）到收敛。**一元泰勒 + 线性最小二乘的组合拳**——两门课在同一支 API 里汇合。

## 3. 极值：OpenCV 的"智能"大多是求极值

- **必要条件 ∇f=0**：梯度⊥等值线 ⇒ Canny 沿梯度抑制的几何依据。
- **Otsu**（`cv2.THRESH_OTSU`）求类间方差最大的阈值（见[04-概率统计](04-概率论与数理统计.md)）；**`cv2.solvePnPRefineLM`** 求重投影误差最小的位姿（见[07-数值优化](07-数值优化与李群.md)）。
- **隐函数**：圆 `x²+y²=r²` 的梯度 `(2x,2y)` 指向径向——Hough 圆用边缘法向找圆心的依据。
- **链式法则**：反向传播的骨架（见[10-深度学习数学](10-深度学习数学.md)）。

## 4. 积分：面积、质矩与积分图

- **`cv2.contourArea`**：格林公式离散版 `Σ(x_i·y_{i+1}−x_{i+1}·y_i)/2`。
- **`cv2.moments`**：零阶矩=面积（二重积分黎曼和）、一阶矩=质心、二阶矩=惯量；`cv2.HuMoments` 构造平移/旋转/尺度不变特征，供 `cv2.matchShapes` 形状匹配。
- **`cv2.integral`（积分图）**：矩形区域和 O(1) 查询——Haar 级联人脸检测 `cv2.CascadeClassifier` 提速千倍的秘密。

## 5. 傅里叶变换：空间域 ↔ 频率域

`cv2.dft` / `cv2.idft`：

- 周期纹理（条纹、摩尔纹、屏摄网格）在频谱上是**离散亮点** ⇒ 打掩码再 `idft` 即去除。
- 高斯核的傅里叶变换仍是高斯且无负瓣 ⇒ 模糊不振铃；盒状核的 sinc 有负瓣 ⇒ 会振铃。
- 平移定理 `f(x−d) ⇔ F(u)·e^{−i2πud}` ⇒ **`cv2.phaseCorrelate`** 用频谱相位差算亚像素平移，模板配准神器。

```python
f = cv2.dft(np.float32(img), flags=cv2.DFT_SCALE | cv2.DFT_REAL_OUTPUT)
# 低通：中心保留圆域，其余置 0，再 idft 回空间域
```
